# A 图形与符号 · 下半是「形状」

> 7 种。共同点：下半区**没有实物感**，全部由形状、线条、色块、负空间构成。
> 高级感的来源是**克制**——形状少、颜色少、留白多。

| # | 介质 | slug | 主体尺度 | 适合 |
|---|---|---|---|---|
| 1 | 视觉 DNA | `visual-dna` | 居中小 | 人像、动物、植物、单栋建筑 |
| 2 | 解构瑞士 | `deconstruct-swiss` | 30%~45% | 任何有明确轮廓的主体（兜底款） |
| 3 | 瑞士网格 | `swiss-grid` | 45% | 建筑、城市、有几何关系的场景 |
| 4 | 独立杂志封面 | `magazine-cover` | 30% | 人像、小物、静物 |
| 5 | 文化剪影 | `cultural-silhouette` | 20%~30% | 建筑、山、植物、器物、民俗题材 |
| 6 | 一笔线画 | `monoline` | 30%~40% | 轮廓简单清晰：人、动物、器物、单栋建筑 |
| 7 | 正负形 | `negative-space` | 40%~55% | 侧脸、剪影感强的动物、有独特轮廓的器物 |

## 1. 视觉 DNA `visual-dna`

**下半是什么**：从主体身上提炼出的一套视觉标识——像艺术机构给一件藏品做的符号化海报。

**适用**：主体轮廓清晰、有辨识度。人、锦鲤、银杏、自行车、白鹭这类"一个东西就是主角"的图最合适。

**唯一约束**：**不能复刻整个物体**。原文写得很直白——"不要重现整个物体，相反，将其简化为一个可识别的抽象视觉符号"。

| 槽 | 默认 |
|---|---|
| 尺度 | 居中或微偏移，不大 |
| 配色 | 原照提取 1~2 种标志色 + 1 种辅助色，暖白或灰白底 |
| 文字 | 微小编号 / 字母 / 短索引，**不作主标题** |

### 原文模板（可整段复制）

```
将我上传的照片转化为一个独立的、高品质的 3:4 纵向设计海报。将整个画布分为两个完全相等的水平部分：上半部分（50%）和下半部分（50%）。

上半部分——逼真摄影：保留原始主体的结构、逼真的纹理、自然光线、阴影以及原始色彩氛围。只应用细微而精致的色彩分级，以实现美术摄影和独立编辑出版物的美学效果。背景可以自然延伸以适应画布，但绝不能拉伸、扭曲或改变原始主体。

下半部分——抽象视觉身份：提取照片的基本视觉特征：主体的轮廓、结构、姿势和叙事关系。不要重现整个物体。相反，将其简化为一个可识别的抽象视觉符号。使用几何解构、模块化形状、结构化线条、负空间和象征元素，创造一个受高端品牌和实验设计系统启发的中心视觉身份。专注于主体的核心特征，而非细枝末节。即使使用最少的几何元素，抽象符号也必须在视觉上与原始照片保持联系。

视觉风格与设计语言：后数字图形设计、解构瑞士设计、生成符号系统和图解抽象。使用几何模块、精细线条、圆形轨迹、网格、微型符号、数字索引和抽象节点，构建一套系统的视觉语言。

从原照提取一至两种标志性色及一种辅助色，搭配暖白或灰白底，色彩承担区分模块和关系的功能。使用独立平涂印色和克制叠印，避免杂乱配色、廉价霓虹与商业渐变。添加极微弱的孔版颗粒、复印或扫描噪点、纸纤维与局部印刷错位，墨色边缘略不完美。

文字只作可读、微小的编号、字母或简短索引，与具体模块对应，不作主标题。

整体克制、精简，兼有精密秩序、轻微手工误差与文化记忆。避免模板化 Logo、商业 UI、赛博朋克、过重未来感、随机几何堆砌、装饰纹样、密集说明与水印。
```

**翻车点**：下半画成了"原图的极简插画" → 补`不是插画，是符号系统`；符号和原物毫无关系 → 特征抓错了，重看第一眼印象。

## 2. 解构瑞士 `deconstruct-swiss`

**下半是什么**：一套后数字平面设计作品——像 60 年代瑞士设计工作室的实验稿，带孔版印刷的脏感。

**适用**：兜底款。任何有清晰轮廓的主体都能做，尤其适合"照片挺好但想做得更高级一点"。

**唯一约束**：**不能把不同题材套成同一种图形**。原文专门写了这句——每张照片的符号必须长得不一样。

| 槽 | 默认 |
|---|---|
| 尺度 | 居中或微偏移，大面积留白 |
| 配色 | 1~2 种标志色 + 1 种辅助色，暖白/灰白底 |
| 文字 | 微小数字编号 |

### 原文模板（11 篇里最完备的一版，可直接当范本）

```
将上传的照片制作成一张独立的 3:4 竖版设计海报。上下严格各占 50%，在画面正中以平直水平边界直接衔接，无间隙、外框或叠压。若输入为效果截图，只提取作品，去除界面、水印和页面文字。

上半部满版展示原照片，保持主体身份、轮廓、结构、姿态、比例、空间关系、真实材质、自然光影及原生色彩。只作极轻摄影调色、必要等比裁切与背景自然延展，不拉伸、扭曲、替换或改动主体。

下半部从同一照片提炼一个独立自洽的抽象视觉标识。先识别最有辨识度的两至三个特征：轮廓、结构、动作、重复节奏或叙事关系，再用少量几何模块、线条、切割、重叠和负空间压缩表达。抓住主体气质和关联，不复刻完整物象，不画完整风景或插画，也不把不同题材套成同一种图形。

采用后数字图形设计、解构瑞士设计、生成式符号系统与图解抽象语言。主体符号是唯一视觉焦点，居中或微偏移，大面积留白。仅在有结构意义时加入极少圆弧轨迹、局部构造网格、细线、抽象节点及微型符号；不堆多图标，不排成信息图表。

从原照提取一至两种标志性色及一种辅助色，搭配暖白或灰白底，色彩承担区分模块和关系的功能。使用独立平涂印色和克制叠印，避免杂乱配色、廉价霓虹与商业渐变。添加极微弱的孔版颗粒、复印或扫描噪点、纸纤维与局部印刷错位，墨色边缘略不完美；不做厚重污渍、裂纹或统一做旧。

文字只作可读、微小的编号、字母或简短索引，与具体模块对应，不作主标题，不写无效文案或乱码。整体克制、精简，兼有精密秩序、轻微手工误差与文化记忆。禁止模板化 Logo、商业 UI、赛博朋克、过重未来感、随机几何堆砌、装饰纹样、密集说明与水印。
```

⭐ **为什么它最值得当范本**：它把下半区拆成四小段——提炼特征 → 几何压缩 → 设计语言 → 材质收尾。别的介质缺哪段，照这个结构补。

**翻车点**：出"信息图表感"（一排图标）→ 补`不堆多图标，不排成信息图表`；颗粒做旧过头 → 补`不做厚重污渍、裂纹或统一做旧`。

## 3. 瑞士网格 `swiss-grid`

**下半是什么**：瑞士国际主义平面设计（Swiss International Typographic Style）——严格网格、非对称几何、平涂印刷、无衬线信息。

**适用**：建筑、城市、街景、有强几何关系或方向感的照片。

**唯一约束**：**网格必须"严格但不可见"**。所有元素对齐网格线，但整体构成非对称、动态，还允许露出极淡的辅助线"像设计师的工作稿"。

| 槽 | 默认 |
|---|---|
| 尺度 | 约 45% |
| 配色 | 提取 2~3 种识别色 + 黑白 |
| 文字 | 左对齐无衬线小字 2~4 行（一个词 / 一个地点 / 一个日期） |

### 原文模板（可整段复制）

```
请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用 3:4 竖版构图，上下两个区域高度严格 1:1，各占画面 50%。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影与原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志与设计档案质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分提取照片中最具识别性的主体、轮廓、结构与运动方向，以瑞士国际主义平面设计（Swiss International Typographic Style）的方法重构：主体被简化为圆、矩形、弧形、斜线与色带等少量几何元素，依靠位置、比例和方向关系让人认出原物，既抽象又准确。

画面建立在一套严格但不可见的网格之上，所有几何元素都对齐网格线，但整体构成是非对称的、动态的；可以使用大胆的尺度对比（一个极大的圆与一条极细的线）和强烈的对角线，制造现代主义的张力与节奏。

材质强调胶印或丝网印刷的真实质感：平涂色块的细微不均、纸张的哑光与纤维、局部的叠印与套准偏差。可以隐约露出极淡的网格辅助线，像设计师的工作稿。避免数码渐变、3D 渲染和过度光滑的矢量感。

构图以理性网格 + 大量留白为核心，几何主体占据下半部分约 45%，其余为白色或单色的负空间，留白与图形同等重要，形成清晰的视觉层级。

配色从上方照片中提取 2–3 种最具识别度的颜色，配合黑与白，形成高度克制、对比明确的瑞士式色彩关系；纯净、明亮，不灰脏。

文字少量介入，以左对齐的无衬线小字（如 Akzidenz 或 Helvetica 气质）排列 2–4 行信息：一个词、一个地点、一个日期或一行短句，与网格严格对齐，形成文字与图形的理性对话，不限制语种。

网格必须真的存在：能看出画面被一套等距网格切分，几何元素严格坐在网格线上，并隐约露出淡灰色的网格辅助线。禁止自由摆放的扁平色块拼贴，禁止堆叠多个矩形，主体形状以圆、弧、斜线、色带为主。

整体呈现严格网格、非对称几何、平涂印刷、无衬线信息与大量留白共同构成的现代主义视觉。核心原则是：把照片里的情绪，交给秩序来表达。避免装饰性元素、数码渐变、拥挤排版、廉价扁平插画、卡通感和模板化海报。
```

⚠️ **实测（2026-11-24）**：只说"建立在一套严格但不可见的网格之上"，出来是几块自由摆放的平涂色块 + 一条装饰细线，**网格没建立**，读起来是扁平插画。要看见网格，得把"可隐约露出辅助线""元素严格坐在网格线上""禁止自由摆放的色块拼贴""禁止堆叠多个矩形"这四句写进去。补了之后一次就出网格。

代价：抽象度会上去，与原照的对应关系变弱。**这一格本来就是在"能认出"和"有秩序"之间取秩序**，交付时要跟用户说明。

⚠️ 这是**整张海报**的模板（含 ②）。走模式 B 时删掉前两段（"请将我上传的每一张照片……"与"上半部分保留原始照片……"），换成 `10-lower-only.md` 的 ①' 开场，其余照抄。

**翻车点**：出来像 PPT 模板 → 补`非对称`、`强烈对角线`，少用矩形（矩形一多就变版面）；文字排得像表格 → 补`大胆的尺度对比`。

## 4. 独立杂志封面 `magazine-cover`

**下半是什么**：一张包豪斯 / Risograph 孔版风格的抽象构图，像独立艺术杂志的封面。

**适用**：人像、小物、静物。想要"被陈列的藏品"的感觉。

**唯一约束**：**严禁矩形**。原文明确禁止方块拼贴、棋盘格、矩形网格、线条围合的直角框架，只允许圆 / 弧 / 三角 / 楔 / 弯月 / 开放轮廓。
（原因：矩形一多就变成"卡片式排版"，立刻掉档。）

| 槽 | 默认 |
|---|---|
| 尺度 | 约 30%（原文："核心几何组合整体缩小约 70%"） |
| 配色 | 同色系明度变化 |
| 文字 | Didot / Bodoni 式高对比衬线，自由非对称排版 |

### 原文模板（可整段复制）

```
请针对每张上传照片各生成一张独立海报，照片之间不得拼接、混用或同屏组合。画布为 3:4 竖版，上下两个区域高度严格保持 1:1，各占画面 50%，并以干净、平直的水平线作为分界；不得出现边框、卡片、胶带、撕纸、卷边或拼贴投影。

上半区须完整保留对应原始照片，人物身份与五官、发型服饰、动作表情、物体、环境、构图、比例、透视、材质、景深、自然光影及色彩关系均不得改动；仅可进行轻微高级调色、曝光优化和背景自然延展。照片应满幅覆盖顶部、左右两侧并延伸至分界线，清除水印、Logo及非场景文字，不添加无关元素。

下半区以同一张原照为唯一素材来源，将照片中的主体、轮廓、姿态、空间走向、环境、色彩、光影与视觉重心彻底拆解，并重构为现代抽象几何艺术；须保留原照的构图记忆与情绪关联，但不得残留任何写实摄影区域，也不能做成滤镜效果或在照片上叠加几何图形。整体气质采用包豪斯、瑞士实验平面设计、复古独立艺术杂志与Risograph孔版印刷风格。核心几何组合整体缩小约70%，以约30%的常规尺度形成精致、集中的视觉中心，可依据原照重心自由偏移；主体内部保持丰富的大、中、小层级结构，主体外部保留大面积暖白、米白或象牙白纸面留白。

严禁使用矩形、正方形、方块拼贴、棋盘格、矩形网格，以及由线条围合出的直角框架。只可使用圆形、半圆、圆环、圆弧、扇形、椭圆、三角形、楔形、锥形、弯月形、不规则曲面、开放轮廓、缺口、细直线、虚线、曲线、节点、圆点、轨迹与负空间；所有形体、方向和细节均须源自原照，不得添加无关图案。颜色从原照中提取，以同色系明度变化建立层次，避免廉价渐变、霓虹色和杂乱高饱和配色。

下半区需加入与照片内容相关、具有真实含义的1—4词英文艺术标题，以及少量英文辅助文字、索引或编号；字体采用Didot、Bodoni、Didone式纤细修长、高对比度衬线字体，排版自由非对称，可横向、纵向、错位或局部斜体，不套用固定模板，不得出现乱码、伪英文、水印或商业Logo。以少量细线、开放圆弧、点阵和结构节点连接主体与留白。纸面应具有细腻温暖纤维、轻微Risograph颗粒、丝网印刷套印偏差与自然不规则边缘，文字和线条保持清晰。最终只输出一张高清艺术海报。
```

**翻车点**：出了方形色块 → 禁用清单被忽略，把「严禁矩形」提到更靠前；英文标题变伪英文 → 给死具体单词。

## 5. 文化剪影 `cultural-silhouette`

**下半是什么**：一枚文化机构的标识 / 徽章——剪纸拼贴质感、扁平色块、带民艺朴拙感。

**适用**：建筑、山、植物、器物、民俗题材。想要"有文化味但不土"。

**唯一约束**：**单一符号承担全部叙事**。不能堆多个元素，不能有复杂背景。

> ⚠️ 原文只给了下半区写法，上半区按 `00-skeleton.md` 的 ② 段补。

| 槽 | 默认 |
|---|---|
| 尺度 | 居中小符号，**极大留白** |
| 配色 | 大面积纯净色块 |
| 文字 | 极简无衬线，辅助信息极克制 |

### 原文模板（下半区原文 + 上半区按骨架补）

```
将上传照片制作成一张独立的 3:4 竖版海报，不拼接其他图片。画布上下严格各占 50%，以平直水平线分界，无边框、无阴影、无卷边。

上半区完整保留原始照片，主体身份与轮廓、姿态、环境、构图、比例、透视、材质、自然光影及色彩关系均不得改动；仅可进行轻微调色与背景自然延展，清除水印、Logo 及非场景文字。

下半区提取照片中最具识别性的主体、轮廓、结构与叙事关系，不要复制完整场景，而是将其压缩为一个具有记忆性的视觉符号或小型标志系统。删除所有非必要信息，只保留能够代表原物身份的核心形态，通过几何归纳、剪纸拼贴、扁平色块和象征化造型，将真实对象转化为一个类似文化机构标识、艺术徽章或设计工作室 logo 的抽象图形。

画面采用 Japanese poetic geometric naivism、folk-inspired symbol design、minimal editorial iconography、cut-paper collage aesthetic 的视觉语言。主体不追求写实，而强调"最少的信息产生最大识别度"。建筑、人物、动物、植物或器物都应被提炼为简洁轮廓、几何模块和象征符号，例如一个屋顶、一片山形、一种姿态、一种植物结构或一个独特比例关系。

构图保持单一核心符号 + 极大留白。主体像一枚被精心设计的小型文化印章，居中或略微偏移放置，周围保持干净空间。不要加入复杂背景，不要堆叠多个元素，让一个视觉符号承担全部叙事。

造型采用 geometric reduction、flat shape illustration、paper-cut form、symbolic abstraction。使用大面积纯净色块、清晰轮廓和少量内部结构线。保留一点民艺感和儿童绘本式的朴拙感，但整体保持现代设计秩序。形状可以略微不规则，带有手工切割感和人为误差，不要过度精准的商业矢量。不得残留写实摄影区域，不能做成滤镜效果。

避免：霓虹色、商业渐变、模板化 Logo、赛博朋克感、装饰纹样堆砌、密集信息图、卡通玩具感。
```

**翻车点**：变成"扁平插画"而不是"符号" → 补`不是插画，是一枚标识`；符号太精细丢了拙感 → 补`形状可以略微不规则，带手工切割感`。

## 6. 一笔线画 `monoline` 🆕

**下半是什么**：用**一条不间断的线**把主体画出来——像设计工作室的手绘 logo 草稿，线宽从头到尾一致。

**适用**：轮廓简单清晰的主体。人（侧脸、站姿）、动物、器物、单栋建筑、自行车。**轮廓越复杂越不适合**（线会缠成一团）。

**唯一约束**：**线真的只有一条**。
⛔ 不要出现"多条线拼成图形"——那变成线稿插画，不是一笔画。
⛔ 不要交叉太多（最多 2~3 处自交）。

| 槽 | 默认 |
|---|---|
| 尺度 | 30%~40%，居中或微偏移 |
| 配色 | 单色线（近黑或深灰）+ 暖白 / 米白纸底；线宽统一 |
| 文字 | 极小无衬线，一个词或不要 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区只用一条连续不断的线重构主体：提取主体的外轮廓与最具特征的一条内部结构线，用一笔画的方式不间断地走完，线条在转折处圆润、在收尾处自然收笔。线宽从头到尾完全一致，首尾可以不相接，允许最多两处自交。线条必须能让人一眼认出原物，但不可以填色、不可以画阴影、不可以出现断线或双线。

构图保持小尺度主体与大面积留白，主体可居中或略微偏移，留白占据画面一半以上。线条以外的所有区域保持空白的暖白或米白纸面。

配色只用一种深色（近黑或深灰）配合纸底，不用第二种颜色。纸面须有细微纤维与极淡的扫描噪点，线条边缘略不完美，像手工绘制后扫描的效果。

可加一到两个极小的英文词或编号，无衬线字体，字号极小，与线条保持距离。

避免：多条线拼成的线稿插画、填色、阴影、渐变色线、粗细渐变的笔触、卡通描绘、霓虹色、商业渐变、密集装饰。
```

**翻车点**：变成普通线稿（一堆线）→ 补`只有一条线，不间断`；线粗细不均像毛笔 → 补`线宽完全一致`。

## 7. 正负形 `negative-space` 🆕

**下半是什么**：主体**不作为被画出来的东西存在，而是作为"被挖掉的空白"存在**——你看白色是形状，看深色也是形状，两个都成立。

**适用**：有独特剪影的照片。侧脸人像、动物（猫、鸟、马）、器物（吉他、椅子、瓶子）、建筑屋顶线。**正面大头照不适合**（没有剪影）。

**唯一约束**：**正负两块必须同时成立**。
⛔ 只画主体、背景当背景 = 普通剪影，没做正负形。
⭐ 判据：把画面深色和浅色分别看成"图"，两个都能读出一个形状。

| 槽 | 默认 |
|---|---|
| 尺度 | 40%~55%（正负形要够大才读得出来） |
| 配色 | 两色：深（近黑/深棕/墨绿）+ 浅（米白/象牙）；最多加一个强调色 |
| 文字 | 极小，或不要 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区用正负形（figure-ground）方式重构主体：主体本身不被描绘成实体，而是以被挖空的形式出现——深色区域中留出主体的剪影形状，浅色区域由此获得形状，两个区域互为图底，各自都能被读成一个完整图形。主体剪影必须准确对应原照的轮廓与姿态，边缘干净，不描边、不加内部细节。

构图把这一组正负形放在下半区中央或略微偏移，尺度足够大，让正负两块都读得出来；其余区域保持大面积单一浅色留白，不加装饰。

**主体必须跨在深浅交界线上**：深色块不是铺满画面的底色，而是一块有自己轮廓的实体色块（约占画面六成），它的一条边缘就是主体的轮廓——主体的耳、背、尾以浅色从深色里咬进去，身体一半在深色内被挖空、一半向浅色区伸出。这样深色块读作"一块被主体咬出形状的纸"，浅色块读作"主体本身"，两边同时成立。深色块的其余边缘用弧线或斜切，不要四边平直的满幅矩形。

配色只用两种：一种深色（近黑、深棕或墨绿）与一种浅色（米白或象牙），深浅关系明确、边缘锐利。最多允许一个极小的强调色点缀。纸面有细腻纤维与极轻的孔版颗粒，色块边缘略不完美。

可加一个极小的英文词或编号，与图形保持距离，不作主标题。

避免：普通剪影（只有主体是形状、背景只是背景）、描边、内部细节、多层灰阶、渐变、霓虹色、装饰纹样、多个图形并排。
```

**翻车点**：做成了普通剪纸剪影 → 补`浅色区域也必须读出一个形状，与主体互为图底`；剪影不够像 → 换照片（这张的剪影辨识度不够）。

⚠️ **实测三次的走法（2026-11-24，黑猫源图）**，这一格的返工路径很有代表性：

| 版本 | 结果 | 缺什么 |
|---|---|---|
| v1 | 满幅黑矩形 + 内部挖出白猫 | 构图平，像一张色卡 |
| v2 | 去掉矩形后，只剩一只黑猫放在米白底上 | **退化成普通剪影**——图底关系没了 |
| v3 | 深色块占右侧六成，左边缘就是猫的轮廓，猫一半被挖空一半伸出 | ✅ 两边都读得出形状 |

教训：**"加轮廓节奏"和"保图底关系"是两条互相拉扯的要求，只做一条会把另一条做坏。** 所以不要分别补，要一次说清"主体骑在交界线上"这个结构。
