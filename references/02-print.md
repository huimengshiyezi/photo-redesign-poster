# B 纸品印刷 · 下半是「印出来的东西」

> 4 种。共同点：下半区看起来像**一件真实的印刷品**——一张邮票、一份档案、一张地图。
> 高级感的来源是**制版逻辑**：有编号、有标注、有版式规矩，像真有人排版印出来的。

| # | 介质 | slug | 主体尺度 | 适合 |
|---|---|---|---|---|
| 1 | 旅行邮票 | `vintage-stamp` | 邮票占 40%~55% | 旅行、街拍、有回忆感的照片 |
| 2 | Riso 双色 | `riso-poster` | 60%~80% | 人像、街景、物件（明暗块面强的） |
| 3 | 档案图鉴页 | `archive-sheet` | 主体 35% + 三个小图 | 植物、动物、器物、老物件 |
| 4 | 手绘地图 | `map` | 85% 铺满 | 旅行照、街景、有空间纵深的场景 |

---

## 1. 旅行邮票 `vintage-stamp`

**下半是什么**：一枚复古收藏邮票——手绘、彩铅肌理、蜡笔痕迹、丙烯色块，放在大面积暖色纸面上。

**适用**：旅行照、街拍、有回忆感的照片，**以及拍糊了的废片**。

**唯一约束**：**邮票是唯一焦点，四周大量留白**。
⛔ 下半不要铺满——邮票要小、留白要大。这是"收藏品"和"宣传画"的分界线。

| 槽 | 默认 |
|---|---|
| 尺度 | 邮票占下半区 40%~55%，居中 / 微偏 / 局部裁切 |
| 配色 | 有限复古色板：奶油白、暖米色、柔蓝、自然绿、哑黄、珊瑚橙 |
| 文字 | 手写笔记、复古邮戳、微旅行标签；字体如真实邮票印刷或旅行手账 |

### 原文模板（可整段复制）

```
基于上传照片，创建3:4竖版高级编辑海报。上下严格1:1均分，各占50%。

上半：原始照片。完全保留主体、身份、姿态、构图、光影、色彩与写实质感。仅做轻微专业调色与增强。勿重设计、扭曲、不自然裁切或改动重要细节。清除水印与非场景文字。

下半：复古收藏邮票艺术。将同图转化为怀旧手工旅行邮票插画。场景变为小尺度收藏级邮票，置于大面积暖色纸张背景上。邮票是唯一明确焦点，四周大量留白，极简编辑构图，强视觉层级。邮票可居中、微偏或局部裁切，但须保持平衡、呼吸感与珍藏旅行记忆感。

插画风格：手绘、彩铅肌理、蜡笔痕迹、丙烯色块、纸张颗粒、丝网印瑕疵。感觉如：复古旅行手账一页、保存的明信片收藏、旧手工邮票。含柔和瑕疵线条、不均手绘色彩、轻微溢色、可见纸纤维、微印刷瑕疵、手工温度。避免光滑数码插画或矢量。

构图背景：暖象牙/奶油肌理纸背景。大面积留白。去除多余背景细节，仅保留原场景最可识别元素。邮票为情感中心。

配色：提取原片最难忘颜色，重设为有限复古色板：奶油白、暖米色、柔蓝、自然绿、哑黄、珊瑚橙。感觉温暖、平静、怀旧、优雅、可收藏。避免脏灰、过度做旧、过饱和、幼稚色。

排版：仅需时加微妙邮票细节：小段手写笔记、复古邮戳、微旅行标签、微型印刷细节。字体如真实邮票印刷或旅行手账，非现代海报标题。无大标题、Logo、水印或明显品牌。

整体风格：现代艺术书插画+复古旅行明信片+收藏邮票美学。最终如珍贵旅行记忆制成的手工邮票作品。

输出：3:4竖版海报，上半50%真实照片，下半50%基于同图的复古手工邮票插画。优雅、极简、怀旧、高级编辑设计。
```

**为什么它最会救废片**：构图差、光线乱的照片做不了几何类（特征抓不出来），但做成手绘邮票反而成立——因为邮票本来就要"小、模糊、有年代感"，瑕疵变成了风格。

**翻车点**：邮票铺满下半 → 补`占下半区约 45%，四周大量留白`；变精致现代插画 → 补`彩铅肌理、蜡笔痕迹、轻微溢色`；做旧过头 → 原文已写`避免脏灰、过度做旧`。

## 2. Riso 双色 `riso-poster` 🆕

**下半是什么**：一张**只用两种油墨印出来的海报**——粗网点、套位偏移、油墨叠印出第三色。像独立音乐现场和小杂志的印刷物。

**适用**：人像、街景、物件。**明暗块面强**的照片最好（强光、剪影、深色背景）。

**和 `magazine-cover` 的区别**（两个都提 Riso，容易混）：

| | `magazine-cover` | `riso-poster` |
|---|---|---|
| 下半画什么 | **抽象几何构图**（形状重排） | **还是这张照片**（被双色化处理） |
| 抽象程度 | 高，认不出细节 | 低，主体清晰可辨 |
| 关键特征 | 禁矩形、30% 小尺度 | 只有两色、网点、套位错 |

**唯一约束**：**只用两种油墨**。
⛔ 出现第三种颜色（除了两色叠印出来的混合色）= 失败。
⭐ 判据：把画面颜色数一遍，只能数出「墨 A、墨 B、A+B 叠出来的那一色、纸白」。

| 槽 | 默认 |
|---|---|
| 尺度 | 60%~80%，主体铺开 |
| 配色 | 两色任选（经典：荧光粉 + 湖蓝 / 橙红 + 墨绿 / 黑 + 黄） |
| 文字 | 极小无衬线，可放 1~3 行；或纯图无字 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区不改变主体的构图与姿态，而是把整张照片转化为双色孔版印刷品：只用两种油墨颜色，加上纸张本身的白色，不出现第三种颜色。两色以网点叠印的方式构成画面，深色处网点密集、浅色处网点稀疏，两色重叠的区域形成第三种混合色。主体必须清晰可辨，不抽象化、不重排构图。

网点必须粗糙可见，呈规则的圆形或菱形排列，网角约 45 度，网点之间留有纸白空隙，不得做成连续渐变的照片质感。

套位必须轻微不准：两个色版之间有 1~3 毫米的错位，边缘出现一线纸白或颜色重叠，像手工套印的误差。纸面可见纤维、轻微油墨不匀与滚轮痕迹。

构图保留下半区大面积纸白留白，主体可略偏，不强制居中。可加入一到三行极小的无衬线英文，与主体保持距离，不作大标题。

避免：第三种颜色、连续渐变、光滑数码照片质感、霓虹光效、3D 渲染、商业海报排版、多种字体混排、密集装饰。
```

**翻车点**：渐变回来了 → 补`网点之间留有纸白空隙，不得做成连续渐变`；版面对得太准、太干净 → 补`套位有 1~3 毫米错位`；颜色变四五种 → 明确写死两个色值。

⛔ **实测新坑：会做成"相框里的照片"**。只写"保留下半区大面积纸白留白"时，模型把图像缩成一块矩形，四周留一圈均匀白边，像嵌在内嵌卡或相框里，主体根本没铺开。
槽位补三句：`图像必须铺满整个画幅、直接顶到画布四边`、`不得用一圈矩形白边把图像框起来`、`纸白只出现在天空与海面本身（靠稀疏网点与纸底表现），不是外加的白边`。

## 3. 档案图鉴页 `archive-sheet` 🆕

**下半是什么**：一张**博物馆藏品档案卡 / 植物标本页**——主体在中间，四周围着编号、学名、采集地、尺寸、比例尺，旁边还有两三个局部特写小图。

**适用**：植物、动物、器物、老物件、有"标本感"的照片。也适合任何你想让它显得"被研究过"的东西。

**唯一约束**：**标注系统必须成立**。
⛔ 不能只是"在图上随便加几个字"——要有编号、有分类名、有测量、有局部小图，像真的档案馆做出来的。
⭐ 判据：遮住主体，光看四周的标注，能读出"这是什么、多大、哪来的"。

| 槽 | 默认 |
|---|---|
| 尺度 | 主体占下半 35%，三个局部特写各占 8%~10% |
| 配色 | 米黄 / 牛皮纸 / 浅灰蓝档案纸；墨色单色印刷 |
| 文字 | 编号 + 拉丁学名（斜体）+ 采集地 + 日期 + 尺寸；衬线或打字机字体 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一张博物馆藏品档案页：以同一主体为唯一对象，按标本图鉴的版式排布在米黄或浅灰蓝的档案纸上。主体以精细的线描或轻微着色的平涂方式重新绘制，保留最关键的结构特征与比例关系，去除环境与背景。

版式必须包含一套完整的标注系统：左上角一个档案编号（如 NO. 047 / SPECIMEN 12），主体右侧或下方标注分类名称（可为拉丁文斜体）、采集地点、日期、尺寸（长×宽×高），主体下方一条带刻度的比例尺。主体旁边放两到三个局部特写小图，每个小图配一行极小的说明。

印刷质感为单色或双色油墨印在纸上：墨色有轻微不匀，线条边缘略毛，纸面有纤维纹理与极淡的污渍，像存放多年的档案。所有文字必须清晰可读、拼写正确、对齐规整。

构图保持大面积留白，所有元素对齐一套不可见的版心网格，标注与主体之间用细线或虚线连接。

避免：乱码与伪文字、装饰性花纹、彩色渐变、霓虹色、卡通化、密集无秩序的堆叠、现代商业排版风格。
```

**翻车点**：标注变装饰线条（没有真内容）→ 给死每一项的内容；拉丁学名拼错 → 提供准确名称或改用中文；版式挤 → 只留 3 个标注项 + 2 个局部图。

## 4. 手绘地图 `map` 🆕

**下半是什么**：把照片里的场景变成**一张手绘旅行地图**——鸟瞰视角、路线、地标小图标、指北针、地名标注。

**适用**：旅行照、街景、有空间纵深和地点的照片。**纯特写（一朵花、一张脸）不适合**——没有空间可画。

**唯一约束**：**必须能读成"地图"**。
⛔ 画成一堆小图标堆在纸上 = 素材拼贴，不是地图。
⭐ 判据：有明确的**空间关系**（这里到那里有多远、在哪个方向），有路线或边界。

| 槽 | 默认 |
|---|---|
| 尺度 | 地图铺满下半区 85%，不做小图 |
| 配色 | 4~6 色有限地图色板：米黄底、赭石、橄榄绿、灰蓝、砖红 |
| 文字 | 地名（小号无衬线或手写）+ 指北针字母 N + 极小的比例说明 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片中的场景转化为一张手绘旅行地图：视角抬升为略俯视的鸟瞰，保留原场景中最可识别的空间关系——道路走向、水岸线、建筑位置、树丛、地形起伏——并按真实方位关系重新排布成一张可读的地图。

主体所在位置用一个小图标或一个小标记点标出，从该点向外延伸出一条虚线路线，穿过两到三个关键地标，每个地标用简洁的手绘小图标表示（不是照片碎片，是图形化的图标）。加入一个小的指北针与一条比例尺。

制图语言为手绘水彩与钢笔淡彩：线条略带手抖，色块边缘有轻微溢色，纸张有纤维与轻微起伏，局部有淡淡的水痕。配色限定在米黄、赭石、橄榄绿、灰蓝、砖红等有限的地图色板内，不出现鲜艳饱和的荧光色。

版面保持清晰的空间层级：主要路线最粗，次要元素更细更淡，边缘留出纸白。地名标注小而清楚，位置贴近对应元素，不得压住路线。

避免：图标无序堆砌、无空间关系的拼贴、现代 UI 地图风格（如导航 App 界面）、卫星影像质感、霓虹色、立体 3D 建筑、密集文字。
```

**翻车点**：变成"图标大杂烩" → 补`每个图标必须有明确位置，且位置来自原照的空间关系`；画得像导航 App → 补`手绘水彩、线条略带手抖、纸纤维`。
