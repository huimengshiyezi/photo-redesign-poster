# C 材质手工 · 下半是「真的做出来」

> 5 种。共同点：下半区不做抽象，而是**把照片里的东西真的"做"出来**——捏的、剪的、绣的、拼的。
> 高级感的来源是**工艺痕迹**：接缝、折痕、针脚、勾缝、压痕、影子。

| # | 介质 | slug | 主体尺度 | 适合 |
|---|---|---|---|---|
| 1 | 黏土微缩 + 元素图鉴 | `clay-diorama` | 50%~60% | 风景、动物、美食、产品、车 |
| 2 | 纸雕海报 | `paper-cut` | 50%~60% | 建筑、人物、动物、植物 |
| 3 | 纸艺微缩立体 | `paper-miniature` | 50% | 建筑、器物、风景（⚠️ 原文缺失） |
| 4 | 刺绣 | `embroidery` | 55%~70% | 植物、风景、动物、静物 |
| 5 | 马赛克 | `mosaic` | 60%~75% | 建筑、人像、风景、动物 |

⭐ **材质类的通用铁律**：写"像 3D 渲染的模型"必垮。要写**手工的缺陷**——接缝、压痕、毛边、错位。

## 1. 黏土微缩 + 元素图鉴 `clay-diorama`

**下半是什么**：一个奶油白底的手工图鉴页——左边一个黏土微缩主场景，右边 3~5 个拆出来的黏土小元素，配英文标签和弯曲箭头。

**适用**：题材最广的一个。风景、建筑、城市、人物、动物、植物、美食、产品、汽车都能做。

**唯一约束**：**下半不是一张图，是一个"图鉴版面"**。
四块组成：主标题（左上）+ 完整黏土主场景（左下）+ 3~5 个独立黏土元素（右侧）+ 标签箭头。
⛔ 只画一个黏土场景、不做元素拆解 = 做了一半。

⭐ **这是唯一一个默认改分割比的介质**：原文用 **46 : 54**，因为下半的内容量更大。

| 槽 | 默认 |
|---|---|
| 分割比 | **46:54** |
| 视角 | **略俯视的四分之三视角**（别改，这是黏土立体感的关键） |
| 配色 | 原图提取，但整体降饱和、走奶油感 |
| 文字 | 英文手写主标题 + 副标题 + 元素英文标签 + 弯曲箭头 |

### 原文模板（可整段复制）

```
你是3D黏土艺术家、微缩场景设计师和图像合成专家。请根据我上传的任意照片，制作"原始照片＋黏土微缩复刻＋元素拆解图鉴"海报，并一次性输出最终成品。

一、原图保护（最高优先级）
上半部分必须直接使用真实原图，严禁AI重绘、修饰、替换或仿制。人物、物体、颜色、光影、纹理、构图及所有可见细节必须100%不变。仅允许等比例缩放，禁止拉伸、变形、裁切、增删内容或添加滤镜。

二、自动创作与合成
自动完成原图分析、下半部分设计及最终拼接，不输出中间图、不只生成下半部分、不要求用户手动合成。若单次生成无法保证原图不变，必须程序化合成：真实原图置于上方，AI艺术区置于下方；合成后不得再用AI重绘整张海报。

三、智能识别
自动识别主体、结构、色彩、材质、环境和代表性细节。适用于风景、建筑、城市、人物、动物、植物、美食、产品、汽车等任意题材。模型须忠实对应原图，保留主体辨识度与空间关系，不套用固定场景或添加无关元素。

四、版式
采用3:4竖版，上半原图约占46%，下半艺术区约占54%。上半不加文字、装饰或滤镜；按原图比例展示并优先保留完整画面，可调整区域高度或增加留白，禁止强制裁切。下半采用奶油白或浅象牙色背景及轻微纸纹：左上放英文手写主标题、副标题；左下展示完整黏土微缩主场景；右侧放3—5个独立黏土元素，搭配英文标签、弯曲箭头和少量主题装饰。

五、黏土场景与图鉴
将主体及典型环境转化为精致3D软陶微缩模型，采用可爱圆润的黏土定格动画风格，保留标志性轮廓、颜色、结构和空间关系。呈现哑光表面、细腻捏塑纹理、自然接缝、轻微压痕、丰富细节及柔和阴影；使用略俯视的四分之三视角，突出空间层次，主模型须足够大并成为视觉中心。另提取3—5个代表性元素，制作材质、造型、配色和光照统一的独立黏土小雕塑。

六、成品验收
按主题生成简洁准确的英文标题、副标题和元素名称，确保拼写正确、箭头指向准确、留白充足、排版清晰。采用协调配色、柔和棚拍光照和杂志式设计。最终输出完整高清海报：上半真实原图100%不变，下半为精致黏土场景与元素图鉴，上下衔接自然。不得用文字说明代替成品，也不得谎称已完成合成。
```

⭐ **这篇最值得学的地方**：它把"验收"写进了提示词（第六段）——要求模型自查拼写、箭头指向、留白。11 篇里唯一这么做的，效果也最稳。

**翻车点**：元素图鉴没做出来 → 把"右侧放 3—5 个独立黏土元素"提到版式描述第一句；黏土变塑料 → 补`哑光、自然接缝、轻微压痕`；英文标签拼错 → 给死元素名。

## 2. 纸雕海报 `paper-cut`

**下半是什么**：一件立体折纸 / 纸雕拼贴作品——折面、切面、叠层、嵌套，有真实的纸厚度和投影。

**适用**：建筑、人物、动物、植物。想做出"手工感 + 雕塑体积感"。

**唯一约束**：**文字要融进纸结构**。原文要求主文字"可由折纸构件构成"——环绕成弧形、沿轴线延伸、贴合轮廓。
⛔ 文字后贴上去（像加了个标题）就变成普通海报了。

| 槽 | 默认 |
|---|---|
| 尺度 | 50%~60%，可偏置、局部裁切、单向延伸，**不强制居中** |
| 配色 | 原图提取 + 米白/浅灰/柔和马卡龙背景 |
| 文字 | 主文字由折纸构件构成，辅助小字克制 |

### 原文模板（可整段复制）

```
为每一张上传的照片单独制作一张高端设计海报，请勿拼接合成，每张照片独立输出。整体采用 3:4 竖版构图，画面严格按照高度 1:1 划分为上下两个区域，各占画布的 50%。

上半部分保留原图，维持主体结构、写实质感、自然光影与原生色彩氛围。仅做轻微高级摄影调色，呈现艺术杂志、独立出版物或展览摄影的质感。为适配版式，天空、地面或环境背景可自然延展，但主体不得拉伸、变形或改动。清除水印与非场景文字。

下半部分从照片中提取辨识度最高的主体、轮廓、姿态与叙事关系，重构为精致的立体折纸与纸雕拼贴作品。不要机械复刻照片细节，而是通过折面、切面、叠层、嵌套、纸片组合的方式对主体进行转译与简化，保证一眼就能识别，同时赋予清晰的几何结构与真实手工质感。

构图依据主体自身的视觉重心、轮廓走向、体量比例和动势方向重新排布，不强制居中。利用层级关系、大小对比、轴线关系、三角稳定感、斜向张力、前后遮挡、正负形把控营造视觉节奏。主体可适度偏置、局部裁切或单向延伸。大面积留白营造呼吸感，让纸艺造型拥有雕塑体积感，同时兼具现代版式设计的克制与平衡。辅助纸片与几何元素仅用来衬托主体，不可形成第二个视觉焦点。

色彩方案从上半张照片里提取最具辨识性、富有活力的色彩，转化为一套和谐生动的纸艺色调。借助同色系明暗变化、邻近色以及少量对比色区分折面与空间层次。背景选用米白、浅灰、柔和马卡龙色或其他与原图适配的浅色调，大面积留白，仅点缀少量纸纹与抽象几何细节。

采用柔和漫射光，凸显纸纤维、折痕、裁切边缘、纸张厚度以及自然阴影。成品整体干净写实、精致细腻，规避塑料感三维效果、反光 CG 质感以及廉价卡纸风格。

文字排版同样融入纸艺结构与构图之中。根据主体身份、主题、动作、情绪或象征含义提炼简短英文单词或标题，搭配少量编号、地点、状态词或微小注释。主文字可由折纸构件构成，它和主体的相对位置随构图结构选择：环绕成弧形、沿轴线延伸、贴合轮廓、上下承托、交织叠放，或是悬浮在留白区域。文字需要清晰可读，同时成为画面空间结构的一部分。辅助小字精简克制，采用高级简约的版式字体，平衡纸艺的手工温度。

整体突出纸张材质感、几何精度、空间层次、构图秩序与手工温度，打造融合当代纸雕艺术与精致版式设计的视觉语言。无论主体是人、动物、植物、建筑、器物、交通工具还是自然风景，实拍照片与纸艺重构之间都要有清晰巧妙的视觉呼应。拒绝卡通折纸、童趣手工风格、对称均衡构图、过度堆砌、电商展示风以及模板化设计。
```

**翻车点**：出来"扁平剪纸"而不是"立体纸雕" → 补`折面、切面、叠层、纸张厚度、自然投影`；像低多边形 3D → 加排除`避免反光 CG 质感`；文字像后加的海报标题 → 补`主文字由折纸构件构成`。

## 3. 纸艺微缩立体 `paper-miniature`

> ⚠️ **本节原文缺失。** 作者写的是「完整提示词太长贴图里放不下，有需要的可以评论区留言或私信」，只公开了气质描述。
> 下面的模板是按公开描述 + `paper-cut` 骨架**合成的，不是原文**。拿到原文后整体替换本节。

**下半是什么**：一个纸做的微缩立体场景（不是平面纸雕拼贴，是一座小小的纸模型）。

**和 `paper-cut` 的区别**：
- `paper-cut` = 平面上的纸片层叠，靠折面和投影出立体感
- `paper-miniature` = 一个真的站得起来的小场景，有地面、有前后景、有缩微比例

**适用**：建筑、器物、风景。要有明确"场景感"的照片。

**原文公开的气质关键词**（判断成品对不对的标尺）：

> 轻盈、温柔、精致、可触摸、有生活感，同时保持清晰的设计秩序与大量呼吸空间
> 保持真实摄影与微缩手工世界之间清晰而巧妙的视觉对应
> 避免塑料 3D、玩具感、儿童手工感、复杂堆积、过度可爱和电商展示感

| 槽 | 默认 |
|---|---|
| 尺度 | 50%，居中小场景 |
| 配色 | 原图提取，转柔和纸艺色板，暖白 / 象牙底 |
| 文字 | 极少量英文标注与编号，字体简约克制 |

### 合成模板（非原文，可用但待替换）

```
为这张上传照片单独制作一张 3:4 竖版高级海报，不拼接其他图片。画面上下严格各占 50%，以平直水平线分界，无边框与投影。

上半部分完整保留原始照片的主体、结构、姿态、环境、构图、比例、透视、材质、自然光影与色彩氛围，仅做轻微专业调色与背景自然延展，不重绘、不拉伸、不改动主体，清除水印与非场景文字。

下半部分将同一场景重构为一座精致的纸艺微缩立体模型：以卡纸、棉纸与瓦楞纸搭出可站立的小场景，包含地面、主体与少量前后景，比例缩微、边界清晰。呈现纸纤维、折痕、裁切毛边、纸张厚度、层次叠压与柔和自然投影。采用柔和漫射光，略俯视的四分之三视角，前景清晰、后景轻微虚化，让空间有纵深。

色彩从上半张照片提取，转为柔和克制的纸艺色板，背景使用暖白或象牙色纸面，大面积留白。整体气质轻盈、温柔、精致、可触摸、有生活感，同时保持清晰的设计秩序与呼吸空间。

可加入极少量英文标注与编号，字体简约克制，与纸面结构对齐。

避免：塑料 3D 质感、玩具感、儿童手工感、复杂堆积、过度可爱、电商展示风、反光 CG、卡通感、霓虹色与商业渐变。
```

## 4. 刺绣 `embroidery` 🆕

**下半是什么**：一整幅**绣出来的画**——长短针铺色、轮廓用回针绣、丝线有方向性光泽，底布纹理可见。

**适用**：植物、风景、动物、静物。轮廓柔和、色块界限不那么硬的照片最出效果。

**唯一约束**：**必须看得见针脚和布纹**。
⛔ 画成"很像刺绣的插画"（平涂 + 假装有纹理）= 失败。
⭐ 判据：放大能看清一根根线的走向；缩小时整体像一幅画。

| 槽 | 默认 |
|---|---|
| 尺度 | 55%~70%，绣绷占画面主体 |
| 配色 | 原图提取，但降饱和、走棉线质感（略哑） |
| 文字 | 极少；可用绣线缝出的字母，或干脆无字 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅手工刺绣作品：以亚麻或棉布为底，整幅画面由丝线或棉线绣成，不出现任何平涂色块或照片碎片。主体以长短针（缎面绣）铺色，深浅通过换线而非渐变实现；轮廓用回针绣勾边，局部细节用结粒绣或直线绣点缀。

针脚必须清晰可见且方向统一：同一色块内的针脚平行排列，不同色块的针脚走向可略作区分，边缘处能看到针脚起落的小孔。丝线有柔和的方向性光泽，随针脚方向产生明暗变化，不是均匀的平面反光。

底布必须可见：布纹为经纬交错的亚麻质感，未绣到的区域露出布面本身颜色与纤维，边缘可保留一圈未绣满的空白。整幅作品可置于绣绷内或直接铺在布面上，绣绷为简洁木框，不喧宾夺主。

配色从原照提取但整体降低饱和度，转为棉线的哑光质感，颜色数量控制在五到六种以内。

构图保持主体占画面主要位置、四周留白或用布面本身收边。文字极少，若需要则用绣线绣出的简单字母，字迹略不工整。

避免：平涂色块、数码渐变、光滑反光、看起来像刺绣的插画、绣线排列杂乱、荧光色、霓虹色、商业海报排版、多个绣品并排。
```

**翻车点**：像插画、纹理是"画上去的" → 补`同一色块内针脚平行排列，边缘可见针脚起落的小孔`；丝线反光像缎子 → 补`柔和的方向性光泽，不是均匀平面反光`。

## 5. 马赛克 `mosaic` 🆕

**下半是什么**：用**小块嵌片**拼出来的画面——石材、玻璃、陶瓷小方块，块与块之间有勾缝，远看是图，近看是块。

**适用**：建筑、人像、风景、动物。**色块界限清楚**的照片最合适（强光、简洁构图）。

**唯一约束**：**嵌片尺寸统一、勾缝贯通**。
⛔ 变回连续色块（只是"有点方块感"）= 失败。
⭐ 判据：能看见块与块之间的缝连成网，而不是画完再叠一层网格。

| 槽 | 默认 |
|---|---|
| 尺度 | 60%~75%，铺开 |
| 配色 | 原图提取，但受嵌片材质限制（石色/玻璃色，略哑或略透） |
| 文字 | 极少；可用嵌片拼出的字母，或不要 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅马赛克镶嵌画：整幅画面由尺寸基本一致的小块嵌片（tessera）拼成，嵌片为石材、玻璃或陶瓷质感，边长统一，形状略不规整。嵌片之间留有明显的勾缝，勾缝颜色为浅灰或米白，贯连成网，不得断续。

画面的明暗与层次完全由嵌片的颜色与排列决定：同一色区内使用多个相近色值的嵌片做细微变化，形成手工镶嵌的不均匀感；过渡区域不用渐变，用相邻色嵌片的交错完成。远看能读出完整形象，近看能看清一块一块的边界。

嵌片表面有轻微的高低差与角度变化，因此局部产生细碎的高光与阴影，整体呈哑光或半透质感，不是平面印刷。勾缝处略深，形成细密的网格阴影。

构图保留主体的主要形态与位置，四周可用单一色调的嵌片收边，形成画框感。留白区域用浅色嵌片铺满，不露出空白底。

可加入少量用嵌片拼成的简单字母或编号，笔画由小块组成，不追求工整。

避免：连续渐变色块、只有网格叠加感的假马赛克、嵌片尺寸大小不一、勾缝消失、霓虹色、商业海报排版、密集装饰纹样。
```
