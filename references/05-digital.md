# E 数字与影像 · 下半是「屏幕与暗房」

> 5 种。共同点：下半区用的是**机器语言**——字符、像素、磨砂层、制图线、叠影。
> ⚠️ 这一类最容易做成滤镜。**必须靠 `③` 段的三句排除句守住**（见 `00-skeleton.md`）。

| # | 介质 | slug | 主体尺度 | 适合 |
|---|---|---|---|---|
| 1 | 字符网点 | `bitmap-halftone` | 20%~35% | 任何照片（最擅长救构图差的图） |
| 2 | 毛玻璃视窗 | `frosted-glass` | 40%~50% | 建筑、人像、产品 |
| 3 | 像素艺术 | `pixel-art` | 30%~50% | 人像、动物、物件、有图标感的场景 |
| 4 | 工程蓝图 | `blueprint` | 60%~75% | 建筑、器物、机械、家具、车 |
| 5 | 双重曝光 | `double-exposure` | 60%~80% | 侧脸人像、动物剪影、树、单车 |

## 1. 字符网点 `bitmap-halftone`

**下半是什么**：整块由字符、点阵、网点、低分辨率栅格单元构成的图像——远看是图形，近看是字母。

**适用**：任何照片，**尤其是构图差、背景乱、主体小的废片**。
原因：这个介质天生允许"小主体 + 超级大量留白"，能把烂图救成一张空得有理由的作品。

**唯一约束**：**必须由字符构成，不是由色块构成。**

> 下半部分图像由字符、符号、点阵、网点和低分辨率栅格单元构成，而不是连续色块。暗部通过更密集的字符与网点形成，亮部通过更稀疏的排布和留白形成。

⛔ 换成色块 = 变成普通半调滤镜。

| 槽 | 默认 |
|---|---|
| 尺度 | **小**，配超级大量留白 |
| 配色 | 单色或双色（用字符密度而不是颜色深浅表现明暗） |
| 文字 | 位图实验标题（Bitmap / Pixel / Dot-matrix），与图像咬合、穿插、错位。**必须给死一个真词（如 `DITHER`）+ 一个编号，禁止"位图实验标题"这种泛称** |

### 模板（下半区原文 + 上半区按骨架补）

```
将上传照片制作成一张独立的 3:4 竖版实验海报，不拼接其他图片。画布上下严格各占 50%，以平直水平线分界，无边框、无阴影、无卷边。

上半区完整保留原始照片，主体身份、轮廓、姿态、环境、构图、比例、透视、材质、景深、自然光影及色彩关系均不得改动；仅可作极轻调色与背景自然延展，清除水印、Logo 及非场景文字，不添加无关元素。

下半部分只提取照片中最具识别性的主体、轮廓、结构、姿态与叙事关系，重构为位图栅格化 + 字符/网点重构 + 实验字体排版的後数字实验海报。不要完整复制照片，不要保留所有对象，不要逐物转绘；主动删去绝大多数无关背景和细节，只保留最能代表原图灵魂的结构、走势和视觉记忆点，通过 Bitmap Rasterization、Dithering、Typographic Halftone、Character-based Image 重新概括，使人一眼识别它与上方照片之间的对应关系。

下半部分重新做美术判断，真正赋予模型重新导演画面的权力：哪怕原图构图差、背景乱、主体小，也要通过删减、重组、裁切、尺度变化和留白，把它救成一张成立的作品。主体不必完整，不必居中，可根据方向、比例和视觉重心自由安排位置，可偏心、贴边或局部裁切。

构图保持小尺度主体与超级大量留白的关系。留白必须是有意识的构图语言，不是空背景，而是与主体、字符密度、网点层次和排版系统共同构成呼吸感、空间感与节奏感。宁可少画，也不要填满；让空白本身成为画面最重要的组成部分之一。

下半部分图像由字符、符号、点阵、网点和低分辨率栅格单元构成，而不是连续色块。暗部通过更密集的字符与网点形成，亮部通过更稀疏的排布和留白形成；整体必须有清晰层级、节奏和秩序，避免杂乱失控。远看先读到一个强而简洁的整体形象，近看再发现它是由字符和点阵重构而成。

字体与排版是画面的核心组成。可加入一个识别性强的位图实验标题，以及极少量辅助文字、编号、短句或注记；标题可采用 Bitmap Typography / Pixel Typography / Dot-matrix Typography，辅助信息则更小、更克制。文字与图像应彼此咬合、穿插、错位或重叠，形成真正的实验排版，而不是后贴标题。

不得残留任何写实摄影区域，不能做成滤镜效果。避免：霓虹色、商业渐变、赛博朋克感、装饰纹样、密集信息图、卡通感、模板化排版。
```

**为什么它最会救图**：别的介质是"简化形状"，它是"换构成单元"。形状再丑的图，换成字符构成之后都会好看——因为它把画面问题转成了排版问题，而排版问题好解决。

**翻车点**：出来是半调滤镜 → 补`不是连续色块`、`不得残留任何写实摄影区域`；字符糊成一团 → 补`有清晰层级和节奏`；铺满没留白 → 补`小尺度主体与超级大量留白`。

⚠️ **实测（2026-11-24）**：槽里写"位图实验标题"这种泛称，模型会直接写出中文字"位图实验 ▮▮ 标题"，中间夹黑块当字。给死 `DITHER` + `NO.07` 之后标题一次就对。**这是文字乱码的第二次复现，同一格栽两次。**

代价：一写进具体标题，模型会把主体放大来"承托"标题，留白变少。要守留白就再补一句`主体占画面宽不超过 40%，标题字号不超过画面高度的 8%`。

## 2. 毛玻璃视窗 `frosted-glass`

**下半是什么**：几何压缩后的画面 + 一套**区域差异化的半透明磨砂层**——有的地方清晰、有的柔焦、有的透叠。

**适用**：建筑、人像、产品。想要"高级品牌视觉 / 建筑海报"的感觉。

**唯一约束**：**模糊必须分区、分层，不能整块平均虚化。**

> 模糊按层次和区域设计，不是整块平均虚化。主体始终一眼可认。
> **必须能看出"磨砂玻璃"这个实物**：画面上至少有两三块边界明确的玻璃区域，边缘可见一条清晰分界。

⛔ 整块平均虚化 = 普通的背景模糊，毫无设计感。

⚠️ **实测（2026-11-24）**：只写"局部清晰、有的柔焦、有的透叠"，出来的是"主体清晰 + 背景虚化"，像杂志内页，看不见玻璃。补上玻璃分块那句之后，三块竖向磨砂玻璃一次就出来了。

⚠️ **文字必须给死**：这一格默认写"少量现代编辑文字"，模型会自己造词，实测出了 `THETERGOMR`。要写就写死 1~2 个真词（如 `GOLDEN` / `2026`），并给出字号上限与四周安全区。

| 槽 | 默认 |
|---|---|
| 尺度 | 40%~50%，居中，画面平衡 |
| 配色 | 原图提取后**提亮、提纯、去灰、净化、柔化**（比原图更明艳但不刺眼） |
| 文字 | 少量现代编辑文字 |

### 模板（下半区描述 + 构图配色原文 + 上半区按骨架补）

```
将上传照片制作成一张独立的 3:4 竖版现代极简海报，不拼接其他图片。画布上下严格各占 50%，以平直水平线分界。

上半区完整保留原始照片，主体身份、轮廓、姿态、环境、构图、比例、透视、材质、自然光影及色彩关系均不得改动；仅作极轻调色与背景自然延展，清除水印与非场景文字。

下半部分把照片主体的轮廓、结构、姿态和关系压缩成简洁几何、平面色块与纤细线条，再叠加一套区域差异化的半透明磨砂视窗：有的局部清晰，有的柔焦，有的透叠。模糊按层次和区域设计，不是整块平均虚化。主体始终一眼可认，像悬浮在安静洁净的近白空间中，少量现代编辑文字让它更接近建筑海报或高端品牌视觉。

必须能看出"磨砂玻璃"这个实物：画面上至少有两到三块边界明确的磨砂玻璃区域（竖直长条或错位的矩形），玻璃边缘可见一条清晰的分界，玻璃内的主体被磨砂透叠、轮廓软化但仍可认，玻璃外的区域保持干净背景。不是把背景虚化，而是在画面上真正盖了磨砂玻璃板。

构图保持主体居中、画面平衡、节奏克制，并通过正负形、尺度关系和留白控制高级感。背景使用米白色或与原图智能匹配的浅色系，保留大面积空白，使主体像悬浮于安静、洁净的视觉空间之中。

配色从上方照片中提取最有生命力、最有记忆点的颜色作为灵感，而不是直接照搬原始色值。先保留原图的色相身份，再进行提亮、提纯、去灰、净化与柔化，使颜色比原图更明艳、更通透、更有精神，同时保持温柔和治愈感。可自然转化为清澈蓝、湖水青、嫩绿、明黄、珊瑚橙、桃粉、淡紫等轻快综合色，通过清爽的冷暖关系和明度差建立层次。主色鲜明但不刺眼，局部可使用一两处更亮的暖色作为阳光般的点睛，使整体呈现明亮、鲜活、轻盈、柔和、温暖、有空气感的色彩气质。

不得残留任何写实摄影区域，不能做成滤镜效果。避免灰脏、发旧、莫兰迪化、暗褐滤镜、荧光色、廉价糖果感、霓虹色、商业渐变、模板化 Logo。
```

**适用于**：建筑海报、艺术展览视觉、高端品牌设计、现代极简海报、App 概念视觉。

⚠️ 这是**整张海报**的模板（含 ②）。走模式 B 时，把前两句"将上传照片制作成一张独立的 3:4 竖版现代极简海报……"和"上半区完整保留原始照片……"删掉，换成 `10-lower-only.md` 的 ①' 开场，其余照抄。

**翻车点**：糊成一片、主体也糊了 → 补`主体始终一眼可认`，指定"主体区域保持清晰，只在背景和一个局部区域磨砂"；颜色发灰 → 加`不可莫兰迪化`；**只出背景虚化、看不见玻璃板** → 补`画面上至少有两到三块边界明确的磨砂玻璃区域，玻璃边缘可见一条清晰分界`；文字自造词 → 写死 1~2 个真词。

## 3. 像素艺术 `pixel-art` 🆕

**下半是什么**：一张**像素画**——大方格像素、有限色板、靠抖动（dithering）做过渡。

**适用**：人像、动物、物件、有图标感的场景。轮廓简洁的照片最出效果。

**和 `bitmap-halftone` 的区别**（两个都"分辨率低"，容易混）：

| | `bitmap-halftone` | `pixel-art` |
|---|---|---|
| 构成单元 | 字符、网点 | 正方形像素格 |
| 视觉源头 | 印刷、打字机、终端 | 8-bit 游戏机、老电脑 |
| 关键特征 | 文字与图咬合 | 像素格严格对齐、轮廓锯齿 |

**唯一约束**：**像素格必须大且对齐**。
⛔ 变成"马赛克滤镜"（把小图放大的那种糊）= 失败。
⭐ 判据：整个画面的像素格是同一个尺寸，边缘是阶梯状锯齿，不是模糊的方块。

| 槽 | 默认 |
|---|---|
| 尺度 | 30%~50% |
| 配色 | 严格限定 8~16 色，每色是纯色，不渐变 |
| 文字 | 像素字体（Pixel Font），与网格对齐 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅像素画：整个画面由统一尺寸的正方形像素格构成，格子对齐一张严格的水平垂直网格，所有边缘呈现阶梯状锯齿，不出现任何平滑过渡或抗锯齿。

颜色数量严格限定在八到十六种之间，每一种都是纯色，不使用渐变；明暗过渡通过相邻颜色的像素交错排列（dithering）实现，形成点状的过渡带。

先降低信息量再做像素化：主体的细节被概括为极少的色块与轮廓，只保留最能识别主体的形状，多余的纹理与细碎高光被省略。整体像素分辨率不高，一眼能看出是像素图。

构图保留下半区大面积留白，主体居中或略偏，留白区域为纯色背景。

可加入一到两行像素字体文字或数字编号，字体为 8×8 或 5×7 的位图字，与像素网格严格对齐，不出现平滑的抗锯齿字体。

避免：平滑抗锯齿边缘、马赛克滤镜效果、连续渐变、超过十六种颜色、霓虹色、赛博朋克光效、3D 渲染、高清照片质感残留、密集装饰。
```

**翻车点**：像马赛克滤镜 → 补`边缘为阶梯状锯齿，不出现平滑过渡`；颜色太多 → 写死色板数量。

## 4. 工程蓝图 `blueprint` 🆕

**下半是什么**：一张**工程图纸**——深蓝底、白线、尺寸标注、剖面线、标题栏。

**适用**：建筑、器物、机械、家具、车。**有明确结构与比例**的照片。

**唯一约束**：**必须有工程标注系统**。
⛔ 只是"蓝底白线的图" = 一张反色照片。
⭐ 判据：有尺寸线（两头带箭头或斜杠）、有编号、有标题栏、有剖面或爆炸分解。

| 槽 | 默认 |
|---|---|
| 尺度 | 60%~75% |
| 配色 | 深蓝（普鲁士蓝）+ 白线；可加极淡的青色辅助线 |
| 文字 | 工程字（等宽无衬线大写），编号 + 尺寸数字 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一张工程蓝图：以深普鲁士蓝为底，所有图形用白色细线绘制，线条为均匀的工程制图线宽，图形透明无填充，可以看到背后的网格。

主体被还原为结构与轮廓：外轮廓用较粗的实线，内部结构用较细的实线，被遮挡的不可见边用虚线，剖切面用四十五度平行斜线填充。主体可作轻微轴测或正投影处理，但整体仍应与原照的形态对应。

必须包含一套工程标注：三到五处尺寸线（两端带箭头或斜杠，线上方标数字）、两到三处引出线带编号、一个位于右下角的标题栏（内含图名、编号、比例、日期），以及边缘的四角定位标记与网格参考线。

底色蓝必须均匀并带轻微的晒图纸质感：极淡的网格底纹、边缘略深、局部有细微的折痕与褪色。

白线边缘略不锐利，像晒图或打印的结果，不得出现发光的霓虹效果。

文字为工程制图字，等宽、字形方正，全部为浅蓝或白色，字号统一且极小。

避免：霓虹发光、赛博朋克界面、3D 透视渲染、渐变、彩色、装饰性花纹、乱码文字、现代 UI 面板、照片质感残留。
```

**翻车点**：变成反色照片 → 补`图形透明无填充，可见底纹网格，必须含尺寸线与标题栏`；发蓝光像科幻界面 → 补`像晒图纸，白线不发光`。

## 5. 双重曝光 `double-exposure` 🆕

**下半是什么**：两张影像**叠在一张底片上**——主体轮廓里装着另一片风景，轮廓清晰，里面通透。

**适用**：侧脸人像 + 风景、动物剪影 + 树林、单车 + 街道。**要有明确的轮廓**（不然叠不出边界）。

⛔ **硬门槛（实测确认）**：源图必须有**明确剪影 / 强轮廓**——逆光剪影、深色主体压亮背景、侧脸对天空。柔光人像 + 雪景这类"全身都在浅灰调里"的照片，两层都是同一张脸同一片雪，叠不出"轮廓里装另一片景象"，出来只是一张带暗角的虚化照。
补不回来，**换图比改词快**。没有剪影图就改推 `frosted-glass` 或 `pencil-sketch`。

**唯一约束**：**一个实、一个虚**。
⛔ 两层都清晰 = 画面糊成一团。
⭐ 判据：能清楚看主体的外形边界，边界里是另一片景象。

| 槽 | 默认 |
|---|---|
| 尺度 | 60%~80% |
| 配色 | 两层色调统一（同一色系），常用冷调或暖调压住 |
| 文字 | 极少；可加一个小字地名或日期 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区用双重曝光的方式重构：把原照的主体轮廓作为第一层，把从同一张照片中提取的另一种景象（天空、树影、水面、街道纹理、墙面肌理）作为第二层，两层叠印在同一张底片上。

第一层（主体轮廓）保持边缘清晰、形状可辨，作为画面的骨架；第二层（景象纹理）填充在轮廓内部与背景中，越靠近轮廓内部越密集，向边缘渐隐。两层之间不是简单叠加透明度，而是让第二层的明暗在主体内部形成新的体积感与情绪。
```

⛔ **实测新坑（真实人像，非剪影）**：源图是"亮脸 + 中调衣服 + 完整环境"时，模型会把**整张照片原样画出来，再叠一条横穿画面的窄带**，读起来是"照片加了故障特效"，不是双重曝光。
槽位必须写死三句才救得回来：
1. `背景必须完全留白，不得出现原照片的天空、海面、礁石或任何环境元素`
2. `主体整体压成单一的深灰调体块，不要保留皮肤与衣物的固有色和细节`
3. 禁止式：`禁止把原照片当作背景再叠一条横向叠影带，禁止让第二层做成一条横切画面的窄带`

⚠️ 另外：「侧脸对着亮天空」只满足**轮廓硬**，不等于**剪影**。人物本身是亮脸时，必须在槽位里强制压暗，否则第一层没有可被替换的内部空间。
