# 验收与返工

> 出图之后要过的六道关。任一条不过就别交付。

---

## 六条验收

### 1 比例

上下各占 50%（或设定的 46:54），分割线位置误差 **< 1%**。**整张图必须是 3:4。**

```bash
python scripts/check.py poster_001.jpg --composed # 拼接产物：位置按构造值判定，只查接缝
python scripts/check.py poster_001.jpg            # 模型直出：自动找接缝
python scripts/check.py poster_001.jpg --ratio 46 # 黏土类
```

⭐ **凡是走 `compose.py` 拼出来的图，一律加 `--composed`。** 自动找接缝靠"横向色差最强的一行"，接缝两侧材质接近时会找错行（深蓝接深蓝，实测误报 +1.6 个点）。

⚠️ **模型直出这条路，中线守不住。** 实测同一套词三张：50.0% / 43.0% / 46.1%。只要客户或用户要求"上下完全一样大"，就不要靠词，直接走模式 B 拼接（`10-lower-only.md`）。

### 2 上半区保真

把出图的上半区与原图半透明叠加比对（或直接并排看细节）：

| 情况 | 判定 |
|---|---|
| 主体位置、五官、构图、颜色都在 | ✅ 过 |
| 整体有轻微色差 / 亮度差 | ✅ 可接受 |
| 五官变了 / 主体挪了 / 被"美化"了 | ❌ 走分段拼接 |

❌ 时不重写提示词，直接走 `compose.py`：原图在上，下半区在下，程序拼。

### 3 下半区是重构，不是滤镜 ← **最重要的一条**

**把下半区单独截出来看。**

| 看到什么 | 判定 | 怎么改 |
|---|---|---|
| 认得出原物，但材质/构成完全变了 | ✅ 对 | — |
| 认不出是什么 | ❌ 抽太狠 | 特征从 2~3 个减到 **2 个**，挑最显著的 |
| 像原图加了滤镜 / 加了网点 / 加了模糊 | ❌ 是滤镜 | 补 `③` 的三句排除，**尤其第 2 句** |
| 像一张与上半无关的插画 | ❌ 脱钩 | 补「必须与上方照片保持可辨识的视觉对应」 |

⭐ 这一条不需要工具，用眼睛判断。**判断标准就一句：这是"重新做的一张图"，还是"给原图加了效果"？**

### 4 留白

下半区主体占比是否落在设定范围（30% / 45% / 60%）：

- 铺满了 → 写死百分比 + `宁可少画，也不要填满`
- 空得没内容 → 尺度上调 15%，或特征从 2 个加到 3 个

### 5 文字

| 问题 | 改法 |
|---|---|
| 乱码 / 伪英文 | 给死具体单词（1~4 个真词） |
| 字号太大变主标题 | 补「微小、克制、可读」 |
| 压在主体上 | 补「文字与主体保持距离」或「融入结构而非覆盖」 |
| 完全没有文字 | 通常是好事。别为了"像个海报"硬加 |
| **文字与右下角水印打架** | 出图工具的 `AI生成` 水印固定在**右下角**，实测直接压在 `SEAWIND` 上 |

⛔ **文字永远不放右下角。** 三张实测全中：Riso 那行 `SEAWIND` 被水印切成两半。
可选位置：左下角、右上角、左上角。**右下角默认留空给水印，交付时一并说明。**

### 6 分界线

| 问题 | 补哪句 |
|---|---|
| 有阴影 / 卷边 / 厚度 | `平贴、无投影、无卷边、无翘起、无立体厚度` |
| 有边框 / 卡片 / 胶带 / 撕纸投影 | `不得出现边框、卡片、胶带、撕纸、拼贴投影` |
| 不是直线 | `以干净、平直的水平线分界` |

## 症状表：从症状找病根

### 通用症状

| 症状 | 病根 | 改哪 |
|---|---|---|
| 下半像原图加了特效 | `③` 缺第 2 句排除 | 补「不能做成滤镜效果，也不得在照片上叠加几何图形」 |
| 下半残留了一块真实照片 | `③` 缺第 1 句 | 补「不得残留任何写实摄影区域」 |
| 下半是模板化排版 | `③` 缺第 3 句 | 补「不得套用固定的版式模板」 |
| 上下像两张不相干的图 | 缺色彩呼应 | 补「下半区配色必须从上半张照片提取」 |
| 下半画成了插画 | 删得不够 | 补「不要逐物转绘」+「主动删去绝大多数细节」 |
| 主体太小看不清 | 尺度定太死 | 30% → 45% |
| 画面空得没内容 | 抽得太狠 | 特征 2 个 → 3 个 |
| 一次出好几张拼一起 | `①` 没写"每张独立" | 补「不多图拼接，每张照片单独输出」 |
| 上半区被重新画了 | `②` 写太松 | 逐项列六类锁定，别用"保持不变"概括 |
| 英文变乱码 | 没给具体词 | 给 1~4 个真单词 |
| 造出一个像英文的生词（`THETERGOMR`） | 那格的槽写的是"少量编辑文字"，没给词 | 文字一律写死；实在不需要文字就整格留空，别留"少量文字"这种口子 |
| 文字挤在最上沿、紧贴接缝 | 模式 B，①' 的"最上方 6% 留白"没被遵守 | 补「文字不得进入画面上方 10%，全部文字安排在下部」 |
| 颜色脏 / 发灰 | 缺"去灰提纯" | 补「提亮、提纯、去灰」+ 排除「避免灰脏、莫兰迪化」 |
| **质感像叠上去的滤镜**（针脚、嵌片、层次看不见） | `③` 把单元写成了效果词 | **照抄合体片段，把单元写到"一根 / 一块 / 一层"的可见尺度**（26 张测试里刺绣、毛玻璃、双重曝光全栽在这条） |
| 平涂有了但不成立 | 结构的骨架句丢了 | 例：瑞士网格缺「对齐不可见网格、非对称」，就成了扁平插画 |

### 介质专属症状

> **本表是索引，不是源头。** 权威说法在每个介质条目末尾的「翻车点」——改那边就要同步这边，反之亦然。
> 用它的时机：手上已经出了一张废图，从症状反查是哪一格没写死。

| 症状 | 介质 | 补哪句 |
|---|---|---|
| 黏土像塑料 | `clay-diorama` | 「哑光、自然接缝、轻微压痕」 |
| 纸雕像低模 | `paper-cut` | 「纸纤维、裁切边缘、纸张厚度」+ 排除「反光 CG」 |
| 邮票铺满下半 | `vintage-stamp` | 「邮票占下半区约 45%，四周大量留白」 |
| Riso 出现第三色 | `riso-poster` | 写死两个色值 + 「只用两种油墨」 |
| 档案页标注像装饰线 | `archive-sheet` | 给死每一项内容（编号/学名/地点/尺寸） |
| 地图变成图标大杂烩 | `map` | 「每个图标必须有明确位置，来自原照的空间关系」 |

| 马赛克像网格滤镜 | `mosaic` | 「嵌片之间有勾缝，贯连成网」 |

| 浮世绘变动漫 | `ukiyoe` | 「墨线是刻线，色块平涂无渐变，无高光反射」 |
| 绘本变干净卡通 | `picturebook-crayon` | 「颜色在纸纹上留下颗粒断点，边缘有反复涂抹痕迹」 |
| 素描像黑白照片 | `pencil-sketch` | 「所有明暗都由排线构成，亮部留白不作灰」 |
| 分镜四格是同一张切的 | `comic-panel` | 写死「全景/中景/特写/细节」 |
| 像素像马赛克滤镜 | `pixel-art` | 「边缘为阶梯状锯齿，不出现平滑过渡」 |
| 蓝图像反色照片 | `blueprint` | 「图形透明无填充，必须含尺寸线与标题栏」 |

## 返工纪律

⛔ **一次只改一处。** 改三处，出图好了也不知道哪处起的作用。

⛔ **同一方向改到第 3 版还不动 → 不是措辞问题，是介质选错了。**

⚠️ 但先分清是哪种"不动"：

| 现象 | 病根 | 做什么 |
|---|---|---|
| 三版都在同一个毛病上 | 介质和照片不配 | 换介质或换图 |
| 修好 A 就坏 B，B 好了 A 又回来 | **两条约束互相拉扯** | 别分开补，把它们合并成**一句结构描述**（例：正负形的"主体骑在交界线上"同时满足轮廓节奏与图底关系） |
| 越改越好但还没到位 | 只是没写透 | 继续改，别换

⭐ 判据：**同一张照片换个介质重做一遍，比在原来那条词上磨十遍快。**
这类图的成败八成在"介质和照片配不配"，不在"词写得好不好"。

## 怎么跟用户说

⛔ 不要说"下半区的介质重构协议不够完备""`③` 段缺少排除约束"。

✅ 说人话：

> 下半现在看着像给原图加了特效，不像重新做的一张图。
> 我把「不许在原图上叠图形」这句加进去重出一次。

✅ 换介质时说：

> 这个方向词改不动了，问题是这张照片不适合抽几何。
> 换成字符网点试试——它能把构图的问题变成排版的问题。

## 交付必须写清三行

1. **用了什么介质**（用大白话，不报 slug）
2. **下半具体做了什么**（一句话）
3. **我替你补的默认值**（分割比 / 尺度 / 配色 / 文字）

示例：

```
介质：独立杂志封面（下半是包豪斯风的抽象几何，禁止出现方形）

给这张照片抽了两个特征：伞的圆弧、雨滴的重复点阵。下半把它们压成一道大圆弧 + 一组小点，
尺寸缩到 30%，留白占七成。文字用了 STILL RAIN，Didot 斜排。

我补的：分割比 1:1、主体 30%、配色取原图伞面的赭红 + 暖白底、英文标题由我拟的。
想改哪一项说一声。
```
