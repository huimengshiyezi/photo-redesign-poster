# 五段骨架

> 这份文件的结论来自逐字比对 11 篇同类公众号原文：**除了第 ③ 段，其余四段几乎是同一套话。**
> 把它们拆开，就得到「固定骨架 + 可换介质插件」。

---

## 装配顺序

```
① 任务与画幅 → ② 上半区保真 → ③ 下半区重构 → ④ 排版与文字 → ⑤ 质感与排除
```

**顺序本身有意义**：先用 ① 定死画布，再用 ② 把原图焊死，然后 ③ 才有安全的地盘去做重构。
把 ③ 写在 ② 前面，模型会先想下半区，顺手把上半区也一起"设计"了。

---

## 四个可调槽

改词时**一次只动一个槽**，其余锁死。

| 槽 | 写在 ① ② ③ ④ ⑤ 的哪一段 | 可选值 | 默认 |
|---|---|---|---|
| **S1 分割比** | ① | 50:50 / 46:54 / 58:42 | 50:50（黏土类 46:54） |
| **S2 主体尺度** | ③ | 20% / 30% / 45% / 60% | 按介质（见各介质条目） |
| **S3 配色策略** | ③ ⑤ | 原图提取后提纯 / 有限复古色板 / 单色系明度 / 给定色值 | 原图提取后提纯 |
| **S4 文字** | ④ | 无 / 1~4 词英文 / 编号索引 / 手写笔记 | 1~4 词英文 |

⚠️ **S3 在单张上是优点，在系列里是灾难**——"从原图提取"会让每张颜色都不一样。做系列超过 5 张就改成给定色值，见 `07-series.md`。

---

## ① 任务与画幅

### 必写三件事

1. **每张独立**（多图输入时）
2. **3:4 竖版**
3. **上下严格 X:Y**

### 可直接抄的句式

> 请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用 3:4 竖版构图，上下两个区域高度严格 1:1，各占画面 50%。

### 变体

| 情况 | 改法 |
|---|---|
| 只输入一张 | 删掉"每一张照片"，保留"不多图拼接" |
| 主体偏顶/偏底 | `上半约占 46%，下半约占 54%`（黏土篇的做法） |
| 想做长图 | ⛔ 不改。3:4 是这类版式的基准，改比例整套语言就散了 |

### ⛔ 禁写

- 只写"做成一张海报"不写比例 → 模型会随手给 16:9
- "把这几张拼成一组" → 会出九宫格
- "生成上半和下半两张图" → 会给你两张分开的图（要分段生成就明确说"只生成下半区"）

## ② 上半区保真

**这一段的唯一任务：让模型把原图当成不可修改的底片。**

### 必写的六类锁定

⛔ **不要概括成"保持不变"四个字——太弱，模型当没看见。要逐项列。**

| # | 锁定项 |
|---|---|
| 1 | 身份与五官 |
| 2 | 发型服饰 / 物体外形 |
| 3 | 动作表情 / 姿态 |
| 4 | 环境与构图、比例、透视、空间关系 |
| 5 | 材质与景深 |
| 6 | 自然光影与色彩关系 |

### 最完备的一版原文（杂志封面篇，建议直接抄结构）

> 人物身份与五官、发型服饰、动作表情、物体、环境、构图、比例、透视、材质、景深、自然光影及色彩关系均不得改动；仅可进行轻微高级调色、曝光优化和背景自然延展。照片应满幅覆盖顶部、左右两侧并延伸至分界线，清除水印、Logo 及非场景文字，不添加无关元素。

### 三件"允许"（少一件就写不通）

1. **等比缩放**（不是裁切）
2. **轻微调色 / 曝光优化**——「轻微」两个字必须写，不写就会被大改
3. **背景自然延展**以适配画幅

### ⚠️ 最容易被漏掉的一句

> **清除水印、Logo 及非场景文字。**

照片多半带平台水印或时间戳，不显式清除会原样带进海报。11 篇原文里有 3 篇专门写了这句。

### ⛔ 禁写

- "让上半区更美 / 更有质感" → 直接触发重绘
- "统一整体色调" → 上半区会跟着下半区偏色
- "保留原图"（孤零零一句）→ 无效

---

## ③ 下半区介质重构 ← 唯一的真变量

### 三步语法：删 → 建 → 上材质

#### 第一步 删：把原图删到只剩骨架

> 提取照片中最具识别性的**主体、轮廓、姿态、结构与叙事关系**
> 不要复制完整场景，不要逐物转绘
> 主动删去绝大多数无关背景和细节，只保留最能代表原图灵魂的结构、走势和视觉记忆点

⭐ **只抓 2~3 个特征，不要更多。** 抓到 5 个 → 下半区变成插画；抓到 1 个 → 认不出。

⭐ **给模型"重新导演"的权力**（字符网点篇原文，别的篇没这么写，但很关键）：

> 哪怕原图构图差、背景乱、主体小，也要通过删减、重组、裁切、尺度变化和留白，把它救成一张成立的作品。主体不必完整，不必居中。

#### 第二步 建：用介质的最小单元重新搭

| 类别 | 最小单元 |
|---|---|
| 几何类 | 圆 / 半圆 / 圆弧 / 三角 / 楔形 / 斜线 / 色带 / 负空间 |
| 材质类 | 折面 / 切面 / 叠层 / 捏塑体块 / 纸片 / 齿孔 |
| 数字类 | 字符 / 网点 / 点阵 / 栅格单元 / 磨砂层 |

⛔ **介质的最小单元不由你发明**，从 `01`~`05` 五个介质文件里那一格取。

#### 第三步 上材质：让下半"像某个真实的东西"

不是渲染得像，是**有那个东西的物理痕迹**：

> 使用独立平涂印色和克制叠印 / 添加极微弱的孔版颗粒、复印或扫描噪点、纸纤维与局部印刷错位，墨色边缘略不完美

---

### ⛔⛔ 必须写死的三句排除

这三句在原文里反复出现。**缺一句就会退化成滤镜：**

```
1. 不得残留任何写实摄影区域
2. 不能做成滤镜效果，也不得在照片上叠加几何图形
3. 不得套用固定的版式模板 / 不是把照片套进模板
```

⭐ **判据：少写第 2 句，出来就是"加了特效的原图"。** 这是整个 skill 最高频的翻车点。

### 尺度与留白

**尺度不在这里查**——26 个数字都在各介质条目的「槽」表里，这里另立一套只会打架。

- 留白必须写成**构图语言**，不是"空背景"：
  > 留白必须是有意识的构图语言，不是空背景，而是与主体、密度、层次共同构成呼吸感、空间感与节奏感。宁可少画，也不要填满。
- 允许偏移 / 贴边 / 局部裁切，**不强制居中**

⛔ **禁写"画面饱满丰富"**——这类图的全部高级感来自留白。

---

## ④ 排版与文字

### 文字的三条规矩

1. **1~4 个词，且必须有实际含义**（和照片内容相关，不是占位词）
2. **字体族随介质**——写在各介质条目的「文字」槽里（Didot / Bodoni、Bitmap、Helvetica 气质、邮票印刷体、英文手写…），不另立总表
3. **位置自由**：可横向 / 纵向 / 错位 / 局部斜体 / 沿线延伸 / 融入结构

⛔ **唯一固定的位置约束：不许放右下角**，那是出图工具水印的位置（实测把 `SEAWIND` 压成两半）。

### ⛔⛔ 禁写

- **不给具体单词却要求特定语言** → 必出乱码和伪英文
  - ✅ `加入与内容相关的 1~4 词英文标题，例如 THE QUIET ORBIT`
  - ⛔ `加一个英文标题`（模型自己编，八成拼错）
- **要求"大标题 / 主标题要醒目"** → 这类图没有主标题，文字一律是"微排版"
- 要求模型生成手写署名 → 后期叠加

### 尺度

文字高度一般不超过下半区高度的 **5%**。写"微小、可读、克制"三个词比写分数有效。

## ⑤ 质感与排除

### 材质三件套（每样至少写一个）

| 层 | 可选 |
|---|---|
| **基材** | 象牙白 / 暖白 / 奶油色纸张 · 卡纸 · 黏土 · 磨砂玻璃 · 布纹 |
| **颗粒** | Risograph 孔版颗粒 · 纸纤维 · 复印/扫描噪点 · 丝网印颗粒 |
| **瑕疵** | 套印偏差 · 边缘略不完美 · 手工切割误差 · 轻微溢色 · 色块细微不均 |

⭐ **三样齐了才"像真的做出来的"。** 只有基材没有颗粒和瑕疵 = 干净的矢量图，一眼假。

### 排除清单

#### 通用（每种介质都写）

> 避免：霓虹色、商业渐变、赛博朋克感、模板化 Logo、电商展示风、塑料 3D 质感、廉价糖果色、乱码与水印、卡通感

#### 分类追加

| 类别 | 追加排除 |
|---|---|
| 几何类 | 装饰纹样、密集信息图、随机几何堆砌、多个图标并排 |
| 材质类 | 玩具感、儿童手工感、过度可爱、对称均衡构图、反光 CG |
| 数字类 | 光滑数码插画、矢量感、整块平均虚化 |

### ⚠️ 这里和通用生图纪律相反，要说清楚

`yezi-ai-image-prompt` 里有一条铁律是**「排除项一律正向化」**（写"不要紫色"反而召唤紫色）。

**在这类设计提示词里不适用**，原因不同：

| | 通用生图 | 本 skill |
|---|---|---|
| 排除的是什么 | **画面元素**（不要紫色、不要多一个人） | **风格边界**（不要霓虹、不要电商风） |
| 正向化会怎样 | 有效 | **失效**——没有等价的正向表述 |
| 结论 | 必须正向化 | **风格边界用"避免"写，画面元素仍要正向描述** |

⭐ 判断一句话：**你要排除的是"某个东西别出现"，还是"某种味道别沾"？** 前者正向化，后者直接写"避免"。
