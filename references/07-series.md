# 系列与批量

> 你是要发内容的，不是做单张练习。
> 一批图介质不一样，发出去是 N 张不相干的图；介质一样，才是"一个系列"。

---

## 系列的五个锁定项

做系列时这五项**必须锁死**，只让「照片」变：

| # | 锁定项 |
|---|---|
| 1 | 介质（一个，不换） |
| 2 | 分割比 |
| 3 | 配色策略（同一套提取规则 + 同一个底纸颜色） |
| 4 | 文字语言（语种 + 字体族 + 位置习惯） |
| 5 | 基材与颗粒（同一张纸、同一种噪点） |

⛔ **五个只锁了三个就发出去 = 看着像同一个人的不同心情，不像一个系列。**
系列感的本质不是"风格相似"，是**这五样一模一样**。

---

## 哪些介质天生适合做系列

| 介质 | 系列感 | 原因 |
|---|---|---|
| `clay-diorama` | ★★★ | 版式固定（主场景 + 元素图鉴），换内容不换结构 |
| `vintage-stamp` | ★★★ | 邮票本身就是"一套收藏"的语言 |
| `visual-dna` | ★★★ | 符号系统天然成套，编号一起排更明显 |
| `archive-sheet` | ★★★ | 档案卡天生带编号，凑成一组就是档案柜 |
| `riso-poster` | ★★☆ | 双色油墨固定后，整组像一套印刷品 |
| `magazine-cover` | ★★☆ | 杂志有期号感，可做「第 N 期」 |
| `swiss-grid` | ★★☆ | 网格统一，但每张构图差异大 |
| `cultural-silhouette` | ★★☆ | 成套感强，但单张信息量小 |
| `bitmap-halftone` | ★★☆ | 排版变化大，需要克制 |
| `embroidery` | ★★☆ | 材质统一，但每张造型差异大 |
| `paper-cut` | ★★☆ | 同上 |
| `deconstruct-swiss` | ★★☆ | 每张符号不同，容易散 |
| `frosted-glass` | ★☆☆ | 每张都"高级"，放一起会腻 |
| `double-exposure` | ★☆☆ | 单张冲击强，连看会疲劳 |
| `comic-panel` | ★☆☆ | 信息量大，不适合快消式日更 |

⭐ **想持续做系列，选 ★★★ 那四个**：黏土、邮票、视觉 DNA、档案页。

## 批量流程

```
1. 先做 1 张打样
      ↓ 确认介质 + 四个槽
2. 锁死五项，写一份「系列词」
      ↓
3. 每张只改一处：③ 段的「特征描述」
      ↓
4. 一次性跑完
      ↓
5. 统一过一遍验收（重点看第 3 条：是重构不是滤镜）
```

⭐ **系列词只需要一份。** 每张不同的地方只有「特征」那几个词，其余四段一字不动。

---

## 系列词模板

```
【锁定部分 · 每张一字不改】
① 请将我上传的每一张照片分别制作成一张独立的高级设计海报……3:4 竖版，上下严格 1:1……
② 上半区须完整保留原始照片，人物身份与五官……均不得改动……
③ （介质语言，固定）
④ （排版规则、字体族、文字位置，固定）
⑤ （基材、颗粒、瑕疵、排除清单，固定）

【每张只改这一行】
本张照片的辨识特征：<特征 A>、<特征 B>、<特征 C>。下半区据此重构。

【锁定部分 · 继续】
（③ 段的排除三句）
```

## 命名与归档

```
<介质>_<日期>_<序号>.jpg
例：clay_20261124_01.jpg
```

批量时三份都留：

```
orig_01.jpg     原始照片
lower_01.png    单独生成的下半区（走分段拼接时）
poster_01.jpg   成品
```

⛔ 只留成品，后面想换分割比重做就废了。

## 不同平台的尺寸处理

> ⛔ **成品一律 3:4，不做其他比例。** 下面是各平台怎么用它。

| 平台 | 处理 |
|---|---|
| 公众号配图 | 3:4 直接用，宽 ≥1080 |
| 公众号封面 | 2.35:1 —— **另做一张，不能裁这张**（会切掉半边） |
| 小红书 | 3:4 原生适配，不用改 |
| 朋友圈 | 3:4 会被裁成方形，**主体别太靠边** |
| 手机壁纸 | 3:4 裁成 9:19.5，中间的符号要能独立成立 |

## 批量时最容易崩的地方

| 问题 | 原因 | 解法 |
|---|---|---|
| 第 5 张开始画风漂了 | 会话太长，早期上下文被稀释 | 每 5~8 张重开一次，把「系列词」贴进去 |
| 某几张上下比例不对 | 模型偷懒 | 用 `check.py` 批量过一遍 |
| 元素图鉴的英文标签拼错 | 模型自己编 | 提前把元素名列表给死 |
| 配色每张不一样 | "从原图提取"太自由 | 改成给定色板（3 个色值写死） |

⭐ **超过 8 张，一定要锁色板。** "从原图提取"在单张上很聪明，在系列里是灾难。
