# D 绘画插画 · 下半是「画出来的」

> 5 种。共同点：下半区是**一张画**，靠手上功夫成立，不是靠排版。
> ⚠️ 这一类最大的坑是**变成滤镜**——"照片转水墨"这种一键效果满地都是。
> 破解办法只有一个：把**笔触、载体、工序**写到具体，让模型没法偷懒。

| # | 介质 | slug | 主体尺度 | 适合 |
|---|---|---|---|---|
| 1 | 水墨 | `ink-wash` | 40%~55% | 山水、风景、花鸟、器物、写意人像 |
| 2 | 浮世绘 | `ukiyoe` | 50%~65% | 风景、人物、动物、建筑 |
| 3 | 绘本蜡笔 | `picturebook-crayon` | 45%~60% | 孩子、动物、日常、食物 |
| 4 | 素描炭笔 | `pencil-sketch` | 50%~65% | 人像、静物、建筑、动物 |
| 5 | 漫画分镜 | `comic-panel` | 分 2~4 格 | 有人物动作、有叙事的照片 |

---

## 1. 水墨 `ink-wash` 🆕

**下半是什么**：一幅写意水墨——墨分浓淡、笔有中锋侧锋、大片留白，纸是宣纸。

**适用**：山水、风景、花鸟、器物、写意人像。**画面元素少的照片最出效果**（水墨怕满）。

**唯一约束**：**墨要分层次，不能整体灰**。
⛔ "照片转水墨滤镜"的典型症状就是整片灰蒙蒙、没有焦墨、没有飞白。必须写死墨色层级。

| 槽 | 默认 |
|---|---|
| 尺度 | 40%~55%，大量留白 |
| 配色 | 墨 + 宣纸白；最多加一点赭石或花青作点缀 |
| 文字 | 可留极小的竖排落款与一方朱印，**不作为标题** |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅写意水墨画：以宣纸为底，用墨的浓淡干湿表现主体，墨色必须明确分为焦墨、浓墨、重墨、淡墨、清墨五个层次，不得整体呈现均匀的灰色。

用笔必须可见：主体轮廓与主要结构用中锋勾勒，转折处有提按，线条粗细随笔势变化；体积与质感用侧锋皴擦，笔锋散开留下飞白。大面积区域用淡墨一遍或两遍晕染，边缘自然渗化，墨在纸上的水痕清晰可见。

留白是画面的一部分，不是没画到的地方：主体之外的区域保留大片宣纸原色，让空白与墨色共同构成呼吸与空间。主体的部分细节可以省略不画，靠留白暗示。

可在局部以极少量的赭石或花青淡淡着色，仅作点醒，不得大面积上色，不得出现鲜艳色。

版面保留宣纸的纤维与轻微起伏，边缘可略作裁切不齐。可加入极小的竖排落款与一方朱红印章，位置在边角，不进入画面主体。

避免：整体灰调、均匀渐变、彩色水墨、水彩质感、油画笔触、数码滤镜效果、贴图纹理、霓虹色、现代排版字体。
```

**翻车点**：整体发灰 → 补`必须出现焦墨（最黑）与飞白（纸白透出）`；变成彩色水彩 → 补`仅墨为主，点缀色不超过两处`。

⛔ **实测新坑**：「点缀色仅作点醒」这句约束不住面积。写了`可局部以极少量赭石或花青淡淡着色`，模型会把**整片海面**染成花青，从写意水墨滑向淡彩。
槽位必须把面积写死：`点缀色总计不超过画面面积的 5%，且只落在主体的一处，不得铺满任何一个物体或整片背景`。

## 2. 浮世绘 `ukiyoe` 🆕

**下半是什么**：一幅**木版套色画**——平涂色块、墨线勾轮廓、和纸肌理，云纹水纹当装饰。

**适用**：风景、人物、动物、建筑。有明确轮廓线和色块分割的照片。

**唯一约束**：**色块平涂 + 墨线轮廓**。
⛔ 出现渐变、光影过渡、写实渲染 = 不是木版画。
⭐ 木版画的每个颜色都是"一块一块印上去的"，不是"画出来的明暗"。

| 槽 | 默认 |
|---|---|
| 尺度 | 50%~65% |
| 配色 | 限定 5~7 色平涂：靛蓝、朱红、藤黄、墨黑、米白、灰绿 |
| 文字 | 可留竖排题签与印章，位于边角 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅浮世绘木版画：画面由若干块平涂的颜色构成，每一种颜色是一块独立的色版，颜色内部完全均匀，不出现渐变、不出现过渡、不出现写实的光影渲染。

所有形状的边缘用墨线勾勒：墨线粗细均匀、端头利落，像用刻刀刻出来再印上去的，线宽约等于画面高度的千分之三。主体、云、水、树、建筑都用这样的墨线勾边，线条可以断，但不能虚。

明暗关系不靠渐变，靠换色块：同一物体的受光面与背光面用两个不同明度的平涂色块直接拼接，交界处一道墨线。

可加入木版画的经典装饰母题：卷曲的云纹、平行的水波纹、放射状的雨线或光晕，作为背景纹理，但只能点缀，不得覆盖主体。

纸张为和纸质感，有纤维与轻微吸墨不匀，局部可见木版压印的凹凸与套色轻微的错位。整体颜色限定在五到七种之内。

可在角落加入极小的竖排题签与一方红色印章，字体为传统书写体，不作大标题。

避免：渐变、写实光影、照片质感、动漫风格、厚涂油画、3D 渲染、霓虹色、超过七种颜色、现代网页排版。
```

**翻车点**：变成日式动漫插画 → 补`墨线是刻线，色块平涂无渐变，无高光反射`；颜色太多 → 写死 6 个色值。

## 3. 绘本蜡笔 `picturebook-crayon` 🆕

**下半是什么**：一页儿童绘本插画——蜡笔或油画棒画的，涂色不匀、笔触可见、偶尔涂出线外。

**适用**：孩子、动物、日常场景、食物、家庭照。**氛围温柔、题材轻的照片**最好。

**唯一约束**：**要保留"手的不准"**。
⛔ 涂得太干净、线条太完美 = 变成矢量卡通，童书的味道全没了。
⭐ 判据：能看见蜡笔在纸纹上留下的颗粒和涂出界的地方。

| 槽 | 默认 |
|---|---|
| 尺度 | 45%~60%，留白给手写文字 |
| 配色 | 温暖有限色板：暖黄、砖红、草绿、天蓝、米白 |
| 文字 | 手写体或手写印刷体，可有一句短句，位置随意 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一页儿童绘本插画：用蜡笔或油画棒在粗糙的图画纸上绘制，笔触必须清晰可见——颜色在纸纹上留下颗粒状的断点，同一块颜色里深浅不均，边缘能看到蜡笔反复涂抹的痕迹。

线条用深色蜡笔勾画，线条不完美：略有抖动，接不上的地方就断开，转角处圆钝，个别地方反复描过而变粗。颜色可以涂出线外一点点，也可以在线内留白没涂满，这是手绘的一部分。

不追求写实比例与光影，把复杂的细节省略掉，只留下能认出主体的最少信息。人物可以简化，表情温和。

配色限定在温暖有限色板内，颜色数量不超过六种，每种颜色都不纯，带一点纸的底色。

构图保持主体占画面主要位置，四周留出空白区域，空白更利于呼吸。可在留白处加一句手写的短句，字迹不工整，颜色与画面协调。

纸面必须可见粗糙的图画纸纤维与轻微凹凸，可有一点被橡皮擦过的浅痕。

避免：矢量卡通、干净平滑的色块、完美对称、数码渐变、荧光色、3D 渲染、商业插画风格、过度可爱化、密集装饰。
```

**翻车点**：变成干净卡通 → 补`颜色在纸纹上留下颗粒状断点，边缘可见反复涂抹痕迹`；太幼稚 → 补`不追求写实比例，但保留主体的辨识度`。

## 4. 素描炭笔 `pencil-sketch` 🆕

**下半是什么**：一张铅笔或炭笔素描——靠排线出明暗，纸纹吃铅，有擦抹的痕迹。

**适用**：人像、静物、建筑、动物。**光影关系明确**的照片最好。

**唯一约束**：**明暗必须靠排线**。
⛔ 平涂灰色当阴影 = 变成黑白照片。
⭐ 判据：能看出一根一根的线，且线的方向随形体走。

| 槽 | 默认 |
|---|---|
| 尺度 | 50%~65% |
| 配色 | 单色（ graphite 灰 / 炭黑）+ 纸色 |
| 文字 | 通常不要；需要时用手写签名式的小字 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一幅铅笔或炭笔素描：所有明暗关系都由排线构成，不出现平涂的灰面。亮部留白，中间调用稀疏的斜排线，暗部用密集交叉排线叠加，最深处接近纸黑。

排线的方向必须随形体走：表现圆柱与曲面时线随转折弯曲，表现平面时线保持平行，表现布料与毛发时线松散并带弧。线条的轻重通过手腕压力变化，起笔略重、收笔渐轻。

必须保留素描的过程痕迹：可擦出的高光、被橡皮提起的纸面毛糙、局部用纸擦笔抹开的柔和过渡、辅助定位的极淡长线。

纸面有可见的颗粒纹理，铅笔的石墨只在纸纹凸起处附着，形成细密的白色空隙。画幅边缘允许有未画满的部分，整体不必填满。

构图保持主体为主要视觉中心，四周留出空白，不画背景或只作极简暗示。

不要出现任何文字；若必须有，只加一个手写的短签名，位于角落，字号极小。

避免：平涂灰色、照片滤镜质感、数码笔刷、彩色、过度精细的写实描摹、清晰的矢量线条、油画面貌、霓虹色、装饰边框。
```

**翻车点**：像黑白照片 → 补`所有明暗都由排线构成，亮部留白不作灰`；线条太整齐像印刷 → 补`允许辅助定位的极淡长线、被擦过的痕迹`。

## 5. 漫画分镜 `comic-panel` 🆕

**下半是什么**：**2~4 格黑白漫画**——分格线、网点、对白框，像从一本漫画里撕下来的一页。

**适用**：有人物动作、有叙事的照片（人在做某件事）。**纯静物、纯风景不适合**（没东西可讲）。

**唯一约束**：**每格的内容必须不一样**。
⛔ 把照片切成四块 = 失败，那只是剪裁。
⭐ 判据：四格连起来能读出一个过程——发生了什么、然后呢。

| 槽 | 默认 |
|---|---|
| 布局 | 2 格（上下）或 4 格（2×2），格与格留白 8~12px |
| 配色 | 黑白 + 网点灰阶；最多加一个专色（红或黄） |
| 文字 | 对白框 / 拟声词 / 旁白框，字体为漫画手写体 |

### ③④⑤ 合体片段（接在骨架 ①② 之后）

```
下半区把照片重构为一页黑白漫画分镜：将画面分割为四格（两行两列），格与格之间留出均匀的白色间隙，分格线为干脆的黑线，粗细一致，四角为直角。

四格内容各不相同，共同讲述同一件事，按阅读顺序推进：
第一格为全景，交代主体所处的环境与位置；
第二格为中景，表现主体的姿态与动作；
第三格为特写，放大最有信息量的局部（手、眼睛、一个物件）；
第四格为细节或反应，给出一个收束性的小画面或留白。
不得把同一张图切成四块充当分镜。

画风为黑白漫画：线稿用均匀的蘸水笔线条，暗部与肤色用网点纸填出灰阶（规则的圆点或斜线网点），高光留白。不出现连续渐变的灰度。

可加入一到两个对白框或拟声词框，框为简洁的圆角或矩形，内含短句，字体为漫画手写体。对白框位置不得遮挡主体关键信息。

四格可统一在一个外框内，也可无外框直接排在纸上。纸面保持干净的白色，可保留极淡的网点透痕。

最多允许一个专色（红色或黄色）用于强调，不得多色。

避免：把照片切块当分镜、连续灰阶、彩色、日式网点过密、密集的文字气泡、3D 渲染、霓虹色、照片质感残留。
```

**翻车点**：四格是同一张图切块 → 明确写`第一格全景 / 第二格中景 / 第三格特写 / 第四格细节`；网点变灰阶 → 补`网点为规则圆点，不出现连续渐变`。
