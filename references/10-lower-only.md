# 模式 B：只生成下半区，程序拼接

> 目标：**不论源图是什么比例、什么内容，成品永远是严格的上下二等分。**
> 结论：这件事模型做不到，只有拼接能保证。

---

## 为什么必须靠拼接

实测同一张照片、同一套五段词，让模型一次出整张，三张的分界线：

| 介质 | 分界线实测 | 偏差 |
|---|---|---|
| 纸雕 | 50.0% | ✅ |
| 档案图鉴页 | 43.0% | −7.0 |
| 工程蓝图 | 46.1% | −3.9 |

同时上半区的 MAE（与原图裁切对齐后的平均色差）是 14~19 —— 照片被重新裁切并轻调过色。

**两个问题同一个根源：模型把"各占 50%"当成构图意图，而不是尺寸约束。**
下半区元素一多，它就挪分界线给自己腾地方。这不是词写得不狠，是这类模型没有"像素级中线"这个概念。

拼接没有这个问题：上半区贴原图（一个像素不动），下半区贴生成图，分界线是代码算出来的。

---

## 什么时候用它

| 情况 | 走哪条 |
|---|---|
| **要求严格二等分** | ⭐ 模式 B，没有例外 |
| **上半区必须原封不动** | 模式 B |
| 源图比例极端（>1.8 或 <0.7） | 模式 B（可配 `--mode blur` 保留完整构图） |
| 赶时间、只出词不出图 | 模式 A（整张直出），交付时说明中线可能偏几个点 |

## 提示词怎么改

模式 B 只生成**下半区那一块**，所以：

### ①' 画幅段（替换骨架的 ①，其余照旧）

```
这不是一整张海报，而是同一张海报的下半区，只输出这一半，不要输出上半区的照片。
画幅为 3:2 横版（宽:高 严格 3:2）。画面顶端就是将来与上半区照片相接的位置，因此最上方 6% 的高度必须是纯净的背景材质，不得出现主体、文字、装饰、投影或贴边元素。
视觉重心安排在画面中下部，水平位置偏右。
```

最后一句的"偏右"是**必填**：失去上下自动呼应之后，重心位置必须显式指定，否则下半区的视觉中心会跟上半区错开。
可选值：偏左 / 居中 / 偏右 / 靠下三分之一。

### ② 上半区保真段：不要写

⛔ 模式 B 里删掉整个 ② 段。写了模型会在同一张画布上再画一遍照片。

### ③④⑤ 段：原样取介质条目

介质片段里凡是提到"下半区"的地方照写，它现在就是整张画布，语义不变。

## 出图尺寸

| 目标 | 生成尺寸 | 说明 |
|---|---|---|
| 默认 | **1536×1024** | 严格 3:2，宽高比 1.5 |
| 高分辨率 | 2304×1536 | 同上放大 |

⛔ **1024×1536 是 2:3，不是 3:4。** 这是最容易踩的坑：竖版尺寸参数里 2:3 很常见，传错会把比例整体带偏。

## 拼接

```bash
# 严格 50:50，上半区裁切满幅
python scripts/compose.py --photo src.jpg --lower lower.png --out poster.jpg

# 上半区完整构图（不裁两侧，用自身模糊延展补齐）
python scripts/compose.py --photo src.jpg --lower lower.png --mode blur --out poster.jpg

# 下半区顶端有暗角或投影，切掉 2% 再接
python scripts/compose.py --photo src.jpg --lower lower.png --trim-top 2 --out poster.jpg
```

**50:50 是构造出来的**：画布高 H 取偶数，`Ht = H // 2`，`Hb = H - Ht`，两者必然相等。
不再依赖模型的任何配合。

### 三种上半区适配

| `--mode` | 效果 | 什么时候用 |
|---|---|---|
| `cover`（默认） | 铺满，裁掉溢出部分 | 源图比例接近 3:2 |
| `blur` | 完整显示 + 自身放大模糊填两侧 | **源图是 16:9 横幅时最合适**，构图一点不丢 |
| `contain` | 完整显示 + 纯色留白 | 只在你能接受明显白边时用 |

⭐ 模式 B 最大的隐藏好处：**上半区换适配方式不影响中线。** 走 A 时裁切和二等分是一起变的，走 B 可以单独调。

⚠️ **竖版源图是这套版式的天生短板。** 3:4 竖图塞进 3:2 的上半区（50% 高度）要裁掉约 **50% 的画面高度**——26 张测试里黑猫、锦鲤、公路三张都吃了这个亏。缝是对的，构图是亏的。
处理顺序：① 优先建议用户换横图；② 必须用竖图时，选主体在画面中部的那几张；③ `--mode blur` 只能补左右，补不了上下的裁切。

## 验收

1. `check.py --composed` 报「像素级等分」—— 不是这条路径做的图，这个判定不成立
2. 接缝处有没有一条明显的灰线或白线（下半区顶部不干净会显出来）→ `--trim-top 2` 重拼
3. 下半区的视觉重心和上半区主体在同侧 —— 这是模式 B 唯一真正变弱的地方，靠 ①' 那句"偏右/偏左"补

⚠️ **不加 `--composed` 会误报。** 自动检测靠"横向色差最强的一行"，这张蓝图的接缝两侧都是深蓝，色差只有 7，它会把标题栏上沿当成接缝，报 51.6%。
